## Milestone Summary

**Key Decisions:**
- Manus API for async deep analysis, Claude for streaming chat
- BrandProfile as multi-table Prisma model (not JSON blob, not single table)
- Context injection into system prompts with ~2K token budget (7500 chars)
- Onboarding wizard — soft prompt, never blocking
- Keyword-based message routing, not LLM-classified
- compileBrandContext() as shared utility for all AI routes
- Haiku 4.5 for enrichment and strategy insights (cost-efficient)
- Hash-based change detection for enrichment (SHA-256)
- Fill-empty + append-deduplicate merge strategy (user edits preserved)
- Open-access pattern: no auth gates on v2 dashboard features

**Issues Resolved:**
- Hikaru responses no longer generic — brand context injected into all AI routes
- Brand profile creation available via wizard or conversational AI interview
- Auto-enrichment from ad data and website URLs reduces manual profile work

**Technical Debt Incurred:**
- Creative Lab generate routes use inline brand context instead of shared compileBrandContext()
- TODO in src/lib/manus/types.ts:42 — refine types after live API testing
- Manus API endpoints lack auth() checks (low risk, API key is server-side)
- enrichmentHash not computed for website enrichment re-runs
