## Milestone Summary

**Key Decisions:**
- Hide Competitors/Benchmarking/Compare from sidebar (keep code, may delete later)
- Gray out Downloads (not available yet)
- Rename Ad Library → Inspiration with sub-items
- Creative Lab is hero feature, placed just below Dashboard
- Dashboard = configurable analytics over full ad database, not personal ads
- V1 moved to /analyser, root route is landing page
- 3-tier pricing (Free $0 / Standard $49 / Pro $149)
- Saved Ads: signIn() button prompt for unauth users
- Category slugs: normalize at API boundary, not in DB
- demographicsError: optional typed field (token_expired | api_error | null)
- :::chart fenced block protocol for AI chart emission
- localStorage config persistence with 10-config limit

**Issues Resolved:**
- Saved Ads broken — no user context for saves → auth-gated with signIn prompt
- Brand detail pages 404 → created brand detail page at /dashboard/v2/ad-library/[pageId]
- Category detail pages 404 → slug normalization at API boundary
- Dashboard duplicated Ad Library → reworked as analytics view
- Demographics failed silently → three-state error handling
- Dashboard/Category drill-down links lost filter → URL param hydration fix

**Issues Deferred:**
- "More insights coming soon" placeholder widget in dashboard (cosmetic)
- CSS placeholder comments in v2-preview-section.tsx (intentional design)

**Technical Debt Incurred:**
