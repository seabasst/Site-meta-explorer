## Overview

Transform the ad library from a basic browse grid into a fast, analytical tool — bringing V1 dashboard depth into the V2 ad library while keeping it slim and quick to scan.

## Requirements

### Analytics (ANLYT)

- [x] **ANLYT-01**: Inline analytics bar — quick stats strip above the ad grid showing total reach, active ad count, format breakdown, top categories
- [x] **ANLYT-02**: Demographic peek — per-brand or per-category mini demographic charts visible while browsing the ad grid

### Browse Experience (BRWS)

- [x] **BRWS-01**: Ad detail lightbox — centered modal overlay on ad click with large media preview, full ad copy, stats, targeting info, dates
- [x] **BRWS-02**: Sort controls — sort by spend/reach/days active/date with clear UI
- [x] **BRWS-03**: View controls — grid density toggle (compact/standard) and optional list view *(list view descoped as optional — density toggle shipped)*
- [x] **BRWS-04**: Load-more pagination — replace numbered pagination with initial 40-60 card batch + "Load more" button appending next batch

### Filters (FLTR)

- [x] **FLTR-01**: Filter UX streamline — cleaner, more intuitive filter bar layout
- [x] **FLTR-02**: Partnership/bylines filter — filter ads by partnership/collaboration status
- [x] **FLTR-03**: Improved active filter chips — better visual treatment and interaction
- [x] **FLTR-04**: Sticky filter bar — filter bar sticks to top on scroll

### Foundation (FNDN)

- [x] **FNDN-01**: Component extraction — break 1044-line monolith into composable components (AdCard, FilterBar, AdGrid, Pagination, StatsBar) to enable clean feature development
