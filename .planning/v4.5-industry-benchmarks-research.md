# v4.5 Industry Benchmarks Research

**Goal:** Create a private admin tool for building industry benchmarks by curating groups of brands, aggregating their advertising data, and comparing individual brands against industry averages.

**Use cases:**
- "Universities in Sweden" — aggregate 10-15 university Facebook pages
- "D2C Golf Brands in Europe" — aggregate golf equipment/apparel brands
- Any vertical where you want to establish "what's normal" for ad strategy

---

## Feature Overview

### Core Workflow

1. **Create Industry** — Name it (e.g., "Swedish Universities"), optional description
2. **Add Brands** — Manually add Facebook page IDs/URLs to the industry
3. **Generate Benchmark** — Fetch fresh data for all brands, compute aggregates
4. **View Results** — See industry averages + individual brand table
5. **Compare** — Select any brand and see how it stacks up vs industry average
6. **Export** — Download benchmark as CSV/JSON

### Key Metrics to Aggregate

Per industry benchmark snapshot:
- **Ad Volume:** Total ads, average ads per brand, median ads per brand
- **Reach:** Total reach, average reach per brand, average reach per ad
- **Demographics:**
  - Aggregate gender split (weighted by reach)
  - Aggregate age distribution (weighted by reach)
  - Aggregate country distribution (weighted by reach)
- **Creative Mix:** % video, % image, % carousel across industry
- **Ad Velocity:** Average ads launched per month across brands
- **Spend Estimate:** Total estimated spend, average per brand

### Comparison View

When comparing Brand X vs Industry:
- Show Brand X metrics alongside industry average
- Calculate index (Brand X / Industry Avg × 100)
- Highlight over/under-indexing (e.g., "Brand X reaches 2.3× more 25-34 males than industry average")

## Data Model

```prisma
model Industry {
  id          String   @id @default(cuid())
  name        String   // "Swedish Universities"
  description String?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  // Owner (you)
  userId      String
  user        User     @relation(fields: [userId], references: [id])

  // Brands in this industry
  brands      IndustryBrand[]

  // Benchmark snapshots over time
  benchmarks  IndustryBenchmark[]
}

model IndustryBrand {
  id              String   @id @default(cuid())
  facebookPageId  String
  pageName        String?  // Fetched from API
  adLibraryUrl    String?
  addedAt         DateTime @default(now())

  industryId      String
  industry        Industry @relation(fields: [industryId], references: [id], onDelete: Cascade)

  // Optional: link to TrackedBrand if also tracked individually
  trackedBrandId  String?

  @@unique([industryId, facebookPageId])
}

model IndustryBenchmark {
  id            String   @id @default(cuid())
  snapshotDate  DateTime @default(now())

  // Counts
  brandsAnalyzed    Int
  totalAdsFound     Int
  avgAdsPerBrand    Float
  medianAdsPerBrand Float

  // Reach
  totalReach        BigInt
  avgReachPerBrand  Float
  avgReachPerAd     Float

  // Demographics (aggregated, weighted by reach)
  genderBreakdownJson   Json?  // [{gender, percentage}]
  ageBreakdownJson      Json?  // [{age, percentage}]
  countryBreakdownJson  Json?  // [{country, percentage}]

  // Creative mix
  videoPercentage    Float
  imagePercentage    Float
  carouselPercentage Float

  // Spend
  totalEstimatedSpend Float
  avgSpendPerBrand    Float

  // Per-brand snapshot data for comparison view
  brandSnapshotsJson  Json?  // [{pageId, pageName, ads, reach, ...}]

  industryId    String
  industry      Industry @relation(fields: [industryId], references: [id], onDelete: Cascade)
}
```

## UI Components

### 1. Industry List Page (`/admin/industries`)

- Table/cards of all industries
- Shows: name, # brands, last benchmark date
- Actions: View, Edit, Delete, Generate New Benchmark

### 2. Industry Detail Page (`/admin/industries/[id]`)

**Tabs:**
- **Brands** — List of brands in industry, add/remove buttons
- **Benchmark** — Latest aggregate stats with charts
- **Compare** — Select a brand, see side-by-side vs industry average
- **History** — Past benchmark snapshots

**Benchmark Tab Contents:**
- Summary cards: Total brands, Total ads, Avg reach, Est. spend
- Gender pie chart (industry aggregate)
- Age bar chart (industry aggregate)
- Country bar chart (top 10)
- Creative mix donut
- Brand table: Name, Ads, Reach, Spend (sortable)

**Compare Tab:**
- Dropdown to select brand from industry
- Side-by-side metrics table with index column
- Butterfly-style demographic charts (brand vs industry)

### 3. Add Brand Modal

- Input: Facebook Page URL or ID
- Validates and fetches page name
- Adds to IndustryBrand table

### 4. Generate Benchmark Flow

- Button triggers API call
- Progress indicator (fetching brand 1/10, 2/10...)
- On complete, redirects to benchmark view

## API Routes

```
POST   /api/admin/industries           — Create industry
GET    /api/admin/industries           — List all industries
GET    /api/admin/industries/[id]      — Get industry with brands & latest benchmark
PUT    /api/admin/industries/[id]      — Update industry name/description
DELETE /api/admin/industries/[id]      — Delete industry + cascade

POST   /api/admin/industries/[id]/brands     — Add brand to industry
DELETE /api/admin/industries/[id]/brands/[brandId] — Remove brand

POST   /api/admin/industries/[id]/benchmark  — Generate new benchmark snapshot
GET    /api/admin/industries/[id]/benchmarks — List historical benchmarks
GET    /api/admin/industries/[id]/benchmarks/[benchmarkId] — Get specific benchmark

GET    /api/admin/industries/[id]/export?format=csv|json — Export latest benchmark
```

## Security Considerations

- All `/api/admin/*` routes require authentication
- Check `session.user.id` matches a hardcoded admin ID or admin role
- No public access to industry benchmark data

## Open Questions

1. **Rate limits:** Fetching 10-15 brands × 500 ads each = significant API load. Batch with delays?
2. **Freshness:** How often to regenerate benchmarks? Manual only, or scheduled?
3. **Brand overlap:** If a brand is in multiple industries, reuse data or fetch separately?
4. **Historical comparison:** Show how industry benchmark changed over time?

## Summary

v4.5 adds a private admin tool for creating industry benchmarks:
- **Manual curation** of brands into industry groups
- **Aggregate metrics** across all brands (reach, demographics, creative mix)
- **Comparison view** showing any brand vs industry average with indexing
- **Database storage** with historical snapshots
- **Export** to CSV/JSON

Estimated scope: 6 phases, ~2-3 days of development.
