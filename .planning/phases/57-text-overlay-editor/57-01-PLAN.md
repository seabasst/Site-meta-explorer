  <action>
1. Install react-konva and konva:
   ```
   npm install react-konva konva
   ```

2. Create `templates/types.ts` with these interfaces:

   **TemplateLayer** interface with fields:
   - `id: string` — unique layer identifier
   - `type: 'image' | 'text' | 'rect'` — layer type
   - `x: number`, `y: number` — position
   - `width: number`, `height: number` — dimensions
   - Text-specific (optional): `text`, `fontSize`, `fontFamily`, `fontStyle` ('bold' | 'italic' | 'bold italic' | 'normal'), `fill`, `align` ('left' | 'center' | 'right'), `lineHeight`, `padding`
   - `role?: 'headline' | 'body' | 'cta'` — semantic role for editing UI
   - Image-specific (optional): `src` (default placeholder URL), `editable` (boolean)
   - Shape-specific (optional): `cornerRadius`, `opacity`, `stroke`, `strokeWidth`
   - `colorRole?: 'primary' | 'secondary' | 'accent' | 'background'` — for color customization

   **TemplateDefinition** interface with fields:
   - `id: string`, `name: string`, `category: string` (product/promo/announcement/lifestyle)
   - `thumbnail: string` — path to preview image (use `/templates/` prefix, actual images later)
   - `width: number`, `height: number` — canvas dimensions in px
   - `format: string` — maps to AdFormat id from format-selector.tsx ('square', 'story', 'landscape', 'portrait')
   - `layers: TemplateLayer[]` — ordered bottom-to-top
   - `defaults: { primaryColor: string; secondaryColor: string; accentColor: string; fontFamily: string; }`

   Export both interfaces. Also export a type `EditMap = Record<string, Partial<TemplateLayer>>` for the edit state.
  </action>
  <verify>TypeScript compiles without errors: `npx tsc --noEmit --strict src/app/dashboard/v2/creative-lab/templates/types.ts` or check via IDE.</verify>
  <done>TemplateLayer, TemplateDefinition, and EditMap types exported and usable by other modules.</done>

  <action>
1. **`hooks/use-load-image.ts`** — Custom hook (do NOT use react-konva-utils, write custom per research):
   - `useLoadImage(src: string | null)` returns `{ image: HTMLImageElement | null, status: 'idle' | 'loading' | 'loaded' | 'error' }`
   - Set `img.crossOrigin = 'anonymous'` (required for canvas export without taint)
   - Clean up on src change (set image to null, reset status)
   - Handle null src gracefully (return idle state)
   - Must be a 'use client' file

2. **`hooks/use-font-loader.ts`** — Font loading hook per research Pattern 4:
   - `useFontLoader()` returns `{ loadFont: (fontFamily: string) => Promise<void>, loadedFonts: Set<string>, isLoading: boolean }`
   - Inject Google Fonts stylesheet link element
   - Await `document.fonts.load()` before marking as loaded
   - Track loading state for UI feedback
   - Deduplicate: skip if font already loaded
   - Must be a 'use client' file

3. **`hooks/use-template-state.ts`** — State management hook per research Pattern:
   - `useTemplateState(template: TemplateDefinition | null)` returns:
     - `resolvedLayers: TemplateLayer[]` — template layers merged with edits
     - `updateLayer(layerId: string, changes: Partial<TemplateLayer>): void`
     - `updateColors(colors: { primary?: string; secondary?: string; accent?: string }): void` — applies colors to all layers with matching colorRole
     - `updateFont(fontFamily: string): void` — applies font to all text layers
     - `resetAll(): void` — clears all edits
     - `edits: EditMap` — raw edit state
   - Reset edits when template changes (new template selection)
   - Import types from '../templates/types'
   - Must be a 'use client' file

4. **`editor/fonts.ts`** — Curated font list (NOT a 'use client' file, just data):
   - Export `CURATED_FONTS: { family: string; category: 'sans-serif' | 'serif' | 'display' | 'monospace' }[]`
   - Include ~25 fonts: Inter, Poppins, Montserrat, Roboto, Open Sans, Lato, Raleway, Nunito, Work Sans, DM Sans, Space Grotesk (sans-serif); Playfair Display, Merriweather, Lora, Libre Baskerville, Cormorant Garamond (serif); Bebas Neue, Oswald, Anton, Righteous, Abril Fatface, Pacifico (display); JetBrains Mono, Fira Code (monospace)
   - Export `DEFAULT_FONT = 'Inter'`
  </action>
