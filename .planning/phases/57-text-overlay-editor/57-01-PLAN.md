  <name>Task 1: Shared types + jszip + generate-config API</name>
  <files>
    src/lib/creative-lab-types.ts

  <action>
    1. Run `npm install jszip` (needed for zip download in Plan 02).

    2. Create `src/lib/creative-lab-types.ts` with shared interfaces:
       - `GenerationSuggestion`: id (string), pillar (string), reasoning (string, user-facing why), format (string), aspectRatio (string like "1:1", "9:16"), tone (string), visualStyle (string), journeyPhase (string), copyAngle (string), imagePrompt (string, for Flux), priority ('high' | 'medium' | 'low'), selected (boolean, default true)
       - `GenerationConfig`: brandName (string), suggestions (GenerationSuggestion[]), brandContext ({ colors: string[], voice: string | null, audience: string[] }), gapSummary (string)
       - `GenerationResult`: suggestion (GenerationSuggestion), status ('idle' | 'loading' | 'success' | 'error'), imageUrl (string | null), error (string | undefined)

    3. Create `src/app/api/creative-lab/generate-config/route.ts`:
       - POST handler accepting `{ pageId: string, category?: string }`
       - Set `export const dynamic = 'force-dynamic'` and `export const maxDuration = 60`
       - Look up brand via `prisma.adLibraryBrand.findUnique({ where: { pageId } })`
       - Fetch cached analysis: `prisma.brandAnalysisCache.findUnique({ where: { brandId: brand.id } })`
       - If no cache exists, return 404 with message "Run analysis first"
       - Optionally fetch brand guidelines if user is authenticated (use `auth()` from `@/auth`). Guidelines are optional -- degrade gracefully without them.
       - Optionally fetch benchmark data if category provided: call the existing benchmark logic or just use the cached analysis distribution data.
       - Build a Claude prompt (use `claude-sonnet-4-20250514` via `@anthropic-ai/sdk`) that:
         - Receives the diversity scores (from cache.scoresJson), distribution data (from cache.distributionJson), brand name
         - Receives brand guidelines (colors, voice, audience) if available
         - Asks for 5-7 ad creative suggestions, each with: pillar, reasoning (1 sentence user-facing), format, aspectRatio, tone, visualStyle, journeyPhase, copyAngle, imagePrompt (for Flux Schnell -- no text in images, high quality photographic/illustration style), priority
         - Pre-filter to top gaps (pillars scoring below 60) to keep prompt focused
         - Cap brand voice input to 200 chars to avoid bloated prompts
       - Parse Claude's JSON response into GenerationSuggestion[] with generated UUIDs
       - Return `GenerationConfig` object with brandName, suggestions, brandContext, and a gapSummary string

    IMPORTANT: Follow the existing pattern from `/api/analyze/diversity/route.ts` for Claude API usage (same import style, same model). Use zod for request body validation. Handle errors gracefully with appropriate status codes.
  </action>
  <verify>
    - `npm run build` succeeds (no type errors)
    - `curl -X POST http://localhost:3000/api/creative-lab/generate-config -H 'Content-Type: application/json' -d '{"pageId":"KNOWN_PAGE_ID"}'` returns a GenerationConfig JSON with suggestions array (requires a brand with cached analysis in the database)
  </verify>
  <done>

    - Without brand guidelines, still returns suggestions based on analysis data alone

    - jszip is installed
  </done>
