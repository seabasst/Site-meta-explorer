**editor-sidebar.tsx** ('use client'):

Props:
- `template: TemplateDefinition`
- `resolvedLayers: TemplateLayer[]`
- `updateLayer: (id: string, changes: Partial<TemplateLayer>) => void`
- `updateColors: (colors: { primary?: string; secondary?: string; accent?: string }) => void`
- `updateFont: (fontFamily: string) => void`
- `resetAll: () => void`

Use useFontLoader() internally for font loading.

**Layout:** Scrollable sidebar with collapsible sections using disclosure/accordion pattern. Use Tailwind styling consistent with design system (dark bg #1a1d2e or similar, light text).

**Section 1: Text Editing**
- Auto-detect text layers from resolvedLayers (filter by type === 'text')
- Group by role: show "Headline", "Body Text", "Call to Action" section headers
- For each text layer:
  - Text input: `<textarea>` for headline/body (multi-line), `<input>` for CTA (single line)
  - Font size slider or number input (range: 12-120, step 1)
  - Text alignment buttons (left/center/right) using icons
  - Bold toggle button
  - Text color picker: native `<input type="color">` with the current fill value
- On change, call `updateLayer(layer.id, { text: newValue })` etc.
- Changes should be immediate (controlled inputs calling updateLayer on every change)

**Section 2: Image**
- Auto-detect image layers where `editable === true`
- For each editable image:
  - "Upload Image" button that opens a file picker (`<input type="file" accept="image/*">`)
  - On file select: create a blob URL via `URL.createObjectURL(file)` and call `updateLayer(layer.id, { src: blobURL })`
  - "Use URL" option: text input where user can paste an image URL (e.g., from generated images). On blur/enter, call updateLayer with the URL.
  - Small preview of the current image source
  - "Reset to default" button that calls updateLayer with the original template src

**Section 3: Colors**
- Show 3 color pickers: Primary, Secondary, Accent
- Initialize from template.defaults (primaryColor, secondaryColor, accentColor)
- Each picker: native `<input type="color">` plus a text input showing the hex value
- Add 6-8 preset color swatches below each picker for quick selection. Include common ad colors: #1235e2, #f43f5e, #10b981, #f59e0b, #7c3aed, #101322, #ffffff, #fafaf9
- On change, call `updateColors({ primary: newColor })` etc.
- Also show a "Apply Brand Colors" button that is a placeholder hint: "Set up Brand Guidelines to auto-apply your brand colors" (no functionality needed, just a helpful hint pointing users to the brand guidelines feature)

**Section 4: Fonts**
- Import CURATED_FONTS and DEFAULT_FONT from './fonts'
- Font selector: dropdown/select grouped by category (Sans-serif, Serif, Display, Monospace)
- Show current font family
- On select: first call `loadFont(fontFamily)` from useFontLoader, then call `updateFont(fontFamily)`
- Show a loading indicator while font loads
- After font loads, the canvas should re-render automatically (since useTemplateState updates the resolved layers which triggers React re-render, which triggers Konva re-render)

**Section 5: Reset**
- "Reset All" button at the bottom (calls resetAll)
- Styled as a subtle/destructive action (not prominent)

**export-controls.tsx** ('use client'):

Props:
- `stageRef: React.RefObject<any>`
- `templateName: string` (for filename)

UI: Two buttons in a row — "Export PNG" and "Export JPG"
- On click, call `stageRef.current.toDataURL({ mimeType, quality, pixelRatio: 2 })` per research Pattern 3
- Trigger browser download with filename `{templateName}-{timestamp}.{ext}`
- Show a brief "Exporting..." state during the toDataURL call (it can take a moment for large canvases)
- Include a resolution info hint: "Exports at 2x resolution for crisp output"
- Handle error case: if stageRef is null or toDataURL fails (e.g., tainted canvas from cross-origin image without CORS), show an error toast or inline error message suggesting the user upload the image instead of using a URL
