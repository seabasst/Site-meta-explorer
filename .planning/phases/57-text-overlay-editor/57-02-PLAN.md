  <action>
    REWRITE `page.tsx` completely. The old 7-step wizard flow (setup > analyzing > results > brief > format-select > generating-image > image-result) is replaced by a 3-state flow:

    **States:**
    1. `search` -- Brand search (keep existing search UI pattern: input field, search results dropdown, brand selection)
    2. `config` -- Config screen (pre-filled by AI) with loading state while generate-config API runs
    3. `gallery` -- Generation results gallery

    **Flow:**
    - Start in `search` state
    - User searches for a brand (reuse existing search logic: fetch `/api/search-pages?q=...`)
    - User selects a brand -> set state to `config`, immediately call `/api/creative-lab/generate-config` with `{ pageId }`
    - While loading: show a loading skeleton for the config screen (shimmer cards)
    - When config loads: render ConfigScreen with the suggestions. User can toggle, edit prompts, customize.
    - User clicks Generate -> set state to `gallery`, fire parallel requests to `/api/creative-lab/generate-batch` for each SELECTED suggestion
    - Parallel generation with concurrency limit of 3 (batch promises in groups of 3 using a simple limiter, NOT all at once -- see RESEARCH.md pitfall 1):
      ```
      const CONCURRENCY = 3;
      for (let i = 0; i < selected.length; i += CONCURRENCY) {
        const batch = selected.slice(i, i + CONCURRENCY);
        await Promise.allSettled(batch.map(s => generateOne(s)));
      }
      ```
    - As each image resolves, update results array -> gallery re-renders showing new image
    - Gallery shows results with download options

    **State management:** Simple useState for: currentState ('search' | 'config' | 'gallery'), config (GenerationConfig | null), suggestions (GenerationSuggestion[]), results (GenerationResult[]), loading flags.

    **Keep from existing page.tsx:**
    - Brand search UI pattern (search input, results list, brand icon display)
    - V2Shell wrapper with title "Creative Lab"
    - useV2() context for darkMode
    - Import of V2Shell, V2Card from '../v2-shell'

    **Remove from existing page.tsx:**
    - All old step/phase state management (the 7-step wizard)
    - BenchmarkComparison usage (still exists as file, just not used in this flow)
    - FormatSelector usage (formats are now AI-suggested per suggestion)
    - GenerationResults usage (replaced by GenerationGallery)
    - All old type definitions that are now in creative-lab-types.ts

    **Import new components:**
    - ConfigScreen from './config-screen'
    - GenerationGallery from './generation-gallery'
    - Types from '@/lib/creative-lab-types'

    **Error handling:**
    - If generate-config fails (brand has no analysis cache): show a message "This brand hasn't been analyzed yet. Run an analysis first." with a link or guidance.
    - If all generate-batch calls fail: gallery shows error states, user can click "Back to Config" and retry.

    The page should be significantly simpler than the old 1172-line version. Target ~200-300 lines since complexity is now in the child components.
