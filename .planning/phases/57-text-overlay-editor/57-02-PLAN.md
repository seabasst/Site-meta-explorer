  - Each card shows: template name, format size label, category badge

  - Cards are clickable (call onSelect)

**template-canvas.tsx** ('use client'):
- Props: `template: TemplateDefinition`, `edits: EditMap`, `stageRef: React.RefObject<any>`, `className?: string`
- Import Stage, Layer, Rect, Text, Image as KonvaImage from 'react-konva'
- Import useLoadImage from '../hooks/use-load-image'
- IMPORTANT: react-konva uses dynamic imports and does not work with SSR. Wrap the component: the file should export a component that uses `dynamic(() => import(...), { ssr: false })` OR handle this by checking `typeof window !== 'undefined'` before rendering Stage. The simplest approach: have template-canvas.tsx export the raw canvas component, and the page.tsx will import it with `next/dynamic` with `ssr: false`.
- Create helper `applyEdits(layer: TemplateLayer, edits: EditMap): TemplateLayer` that merges edit overrides onto the base layer.
- Render a Konva Stage at the template's width/height dimensions. Apply CSS scaling to fit the available space while maintaining aspect ratio — use a wrapper div with `style={{ transform: 'scale(...)' }}` or set the Stage width/height to a scaled-down display size. For the display, compute a scale factor: `Math.min(maxWidth / template.width, maxHeight / template.height)` where maxWidth/maxHeight come from props or a sensible default (e.g., 600px wide). Apply this scale to the Stage's `scaleX` and `scaleY` props, keeping `width` and `height` at the actual template dimensions (this way export gets full resolution).
- For each layer in the resolved layers array:
  - `rect`: Render `<Rect>` with x, y, width, height, fill, cornerRadius, opacity, stroke, strokeWidth
  - `text`: Render `<Text>` with x, y, width, text, fontSize, fontFamily, fontStyle, fill, align, lineHeight, padding. Set `verticalAlign: 'middle'` for CTA role text.
  - `image`: Use the useLoadImage hook. Since there may be multiple image layers, create a small `ImageLayer` sub-component that takes a layer and calls useLoadImage internally. Render `<KonvaImage>` only when image is loaded. Show nothing while loading (the rect behind it provides the background).
- The Stage ref is passed through for export (Plan 03 will call stageRef.current.toDataURL).
