Refactor the diversity analysis backend to read stored classifications instead of calling Claude for classification, and migrate BrandAnalysisCache to the 8-category taxonomy.

Purpose: Eliminate the expensive Claude classification call (~$0.10-0.50 per analysis) by reading from pre-computed AdClassification rows. This is the core value of Phase 64 — making diversity analysis fast and cheap.

Output: Updated Prisma schema + refactored diversity route that reads from DB instead of calling Claude for classification.

<task type="auto">
  <name>Task 2: Refactor diversity route to read from AdClassification</name>
  <files>src/app/api/analyze/diversity/route.ts</files>
  <action>
  Rewrite the diversity route. The overall structure stays similar but Claude Call 1 (classification) is replaced with a DB read.

  **Key changes:**

  1. **Remove the Anthropic import and client** at the top — WAIT, keep it because Claude Call 2 (recommendations) still needs it. Keep `import Anthropic from '@anthropic-ai/sdk'` and `const client = new Anthropic()`.

  2. **Replace the PillarDistribution and Classification interfaces** with new types matching the 8-category taxonomy:
  ```typescript
  import { TAXONOMY, CATEGORY_KEYS, type CategoryKey } from '@/lib/classification/taxonomy';

  type CategoryDistribution = Record<CategoryKey, Record<string, number>>;
  ```

  3. **After fetching ads (keep existing ad fetch logic), replace Claude Call 1 entirely.** Instead of calling Claude, query AdClassification:
  ```typescript
  const adDbIds = ads.map(a => a.id);
  const classifications = await prisma.adClassification.findMany({
    where: { adId: { in: adDbIds } },
  });
  ```

  4. **Check classification coverage.** If fewer than 3 ads are classified, return an error telling the user to classify ads first:
  ```typescript
  if (classifications.length < 3) {
    return Response.json({
      error: `Only ${classifications.length} of ${ads.length} ads are classified. Run classification first (need at least 3).`,
      classifiedCount: classifications.length,
      totalAds: ads.length,
      needsClassification: true,
    }, { status: 422 });
  }
  ```

  5. **Build 8-category distribution** from the DB classifications:
  ```typescript
  const distribution: CategoryDistribution = {
    assetType: {},
    visualFormat: {},
    hookTactic: {},
    messagingAngle: {},
    awarenessStage: {},
    creativeMechanic: {},
    offerType: {},
    intendedAudience: {},
  };

  for (const c of classifications) {
    for (const key of CATEGORY_KEYS) {
      const value = c[key];
      if (value) {
        distribution[key][value] = (distribution[key][value] || 0) + 1;
      }
    }
  }
  ```

  6. **Update diversity score calculation** to use 8 categories. Use TAXONOMY to get max category count for Shannon entropy:
  ```typescript
  const diversityScores: Record<CategoryKey | 'overall', number> = {} as any;
  for (const key of CATEGORY_KEYS) {
    const maxCats = TAXONOMY[key].values.length;
    diversityScores[key] = calcDiversityScore(distribution[key], maxCats);
  }
  diversityScores.overall = Math.round(
    CATEGORY_KEYS.reduce((sum, k) => sum + diversityScores[k], 0) / CATEGORY_KEYS.length
  );
  ```

  7. **Keep the local metrics section unchanged** (ad fatigue, refresh rate, CTA diversity, copy length). These don't depend on classification.

  8. **Update hook quality and concept diversity** to read from DB classifications instead of the Claude response:
  - `hookScores` comes from `classifications.map(c => ({ adId: c.adId, score: c.hookScore, firstLine: ... }))`
  - `clusterCounts` comes from `classifications` using `c.conceptCluster`
  - The ad lookup for firstLine: join with the ads array by adId

  9. **Update funnel balance** to use `awarenessStage` instead of `journeyPhase`. Map the 5 Schwartz stages into funnel buckets:
  ```typescript
  const funnelMap: Record<string, 'awareness' | 'consideration' | 'conversion'> = {
    'unaware': 'awareness',
    'problem-aware': 'awareness',
    'solution-aware': 'consideration',
    'product-aware': 'consideration',
    'most-aware': 'conversion',
  };
  let awarenessCount = 0, considerationCount = 0, conversionCount = 0;
  for (const c of classifications) {
    const bucket = funnelMap[c.awarenessStage] || 'awareness';
    if (bucket === 'awareness') awarenessCount++;
    else if (bucket === 'consideration') considerationCount++;
    else conversionCount++;
  }
  const total = classifications.length;
  const awarenessRatio = total > 0 ? awarenessCount / total : 0;
  const considerationRatio = total > 0 ? considerationCount / total : 0;
  const conversionRatio = total > 0 ? conversionCount / total : 0;
  ```

  10. **Update Claude Call 2 (recommendations)** to reference the new 8-category taxonomy instead of Five Pillars. Change the prompt to list the 8 categories with their distributions. Update the recommendation pillar values to include the 8 taxonomy keys plus the andromeda metric keys. Keep the same output format (summary, biggestGap, andromedaScore, recommendations array).

  In the recommendation prompt, replace "Five Pillars Distribution" with "Creative Taxonomy Distribution (8 dimensions)" and list each of the 8 categories with their distribution counts.

  Update the recommendation `pillar` field options to: `"assetType | visualFormat | hookTactic | messagingAngle | awarenessStage | creativeMechanic | offerType | intendedAudience | refreshRate | hookQuality | conceptDiversity | funnelBalance | ctaDiversity | copyLength"`.

  11. **Update BrandAnalysisCache upsert** to use new column names:
  ```typescript
  assetTypeScore: diversityScores.assetType,
  visualFormatScore: diversityScores.visualFormat,
  hookTacticScore: diversityScores.hookTactic,
  messagingAngleScore: diversityScores.messagingAngle,
  awarenessStageScore: diversityScores.awarenessStage,
  creativeMechanicScore: diversityScores.creativeMechanic,
  offerTypeScore: diversityScores.offerType,
  intendedAudienceScore: diversityScores.intendedAudience,
  ```

  12. **Update the response JSON** to return 8-category distribution and scores instead of 5 pillars. Keep `andromedaMetrics`, `andromedaScore`, `summary`, `biggestGap`, `recommendations`. Add `classifiedCount` and `totalAds` to the response so the frontend can show coverage.

  Remove the per-ad `classifications` array from the response (it was only there because the old route generated them inline — the new taxonomy data is in the DB and will be exposed via Phase 65's classification UI).

  **Remove the video asset query** (`prisma.adAsset.findMany` for video detection) and the `enrichedSummaries` construction — those were only needed to build the Claude classification prompt.

  **Keep `maxDuration = 300`** since the recommendation call can still take time.
  **Keep `export const dynamic = 'force-dynamic'`**.
  </action>
