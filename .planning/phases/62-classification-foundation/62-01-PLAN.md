  <action>
Create `src/lib/classification/taxonomy.ts` defining all 8 classification categories as a single TAXONOMY const object. Each category has:
- `values`: readonly tuple of string literals (for z.enum and type derivation)
- `labels`: Record mapping each value to a human-readable display label
- `description`: One-line description of what this category measures

The 8 categories and their values (from research):

1. **assetType** (8 values): ugc, studio, graphic-design, stock, screen-capture, ai-generated, editorial, mixed
2. **visualFormat** (12 values): talking-head, product-demo, testimonial, lifestyle, before-after, unboxing, tutorial, skit, slideshow, text-overlay, split-screen, other
3. **hookTactic** (11 values): question, bold-claim, statistic, pain-point, curiosity-gap, social-proof, controversy, how-to, direct-address, storytelling, other
4. **messagingAngle** (11 values): price-value, problem-solution, aspirational, educational, social-proof, urgency-scarcity, emotional, comparison, authority, community, other
5. **awarenessStage** (5 values): unaware, problem-aware, solution-aware, product-aware, most-aware
6. **creativeMechanic** (9 values): before-after, listicle, reaction, day-in-life, challenge, transformation, process-reveal, review, other
7. **offerType** (8 values): discount, free-trial, bundle, limited-time, evergreen, seasonal, giveaway, no-offer
8. **intendedAudience** (7 values): broad, niche-interest, demographic-specific, retargeting, lookalike, competitor-audience, other

Export derived types: `type AssetType = typeof TAXONOMY.assetType.values[number]` etc. for all 8.

Also export a `CATEGORY_KEYS` array: `["assetType", "visualFormat", ...] as const` for iteration.

Create `src/lib/classification/schemas.ts`:
- Import TAXONOMY from taxonomy.ts
- Build `ClassificationOutputSchema` using `z.object()` with `z.enum(TAXONOMY.{category}.values)` for each of the 8 categories
- Add `hookScore: z.number().min(1).max(10).describe("1-10 scroll-stopping power")`
- Add `conceptCluster: z.string().describe("2-3 word hyphenated concept label, lowercase")`
- Add `confidence: z.number().min(0).max(1).describe("0.0-1.0 classification confidence")`
- Export the schema and its inferred type: `type ClassificationOutput = z.infer<typeof ClassificationOutputSchema>`

Do NOT use `@anthropic-ai/sdk/helpers/zod` in this file -- that import belongs in the prompt/caller code (Phase 63). This file is pure Zod.

**1. AdClassification** (add after AdAnalysis model, around line 442):
```prisma
model AdClassification {
  id    String @id @default(cuid())
  adId  String @unique
  ad    AdLibraryAd @relation(fields: [adId], references: [id], onDelete: Cascade)

  // 8 classification categories (indexed columns, not JSON)
  assetType         String
  visualFormat      String
  hookTactic        String
  messagingAngle    String
  awarenessStage    String
  creativeMechanic  String
  offerType         String
  intendedAudience  String

  // Quality metrics
  hookScore         Int
  conceptCluster    String

  // Metadata
  confidence        Float    @default(0.8)
  classifiedBy      String   @default("haiku-4.5")
  classificationSource String @default("text")
  schemaVersion     Int      @default(1)
  classifiedAt      DateTime @default(now())

  @@index([assetType])
  @@index([visualFormat])
  @@index([hookTactic])
  @@index([messagingAngle])
  @@index([awarenessStage])
  @@index([creativeMechanic])
  @@index([offerType])
  @@index([adId])
}
```

**2. ClassificationJob** (add after AdClassification):
```prisma
model ClassificationJob {
  id        String   @id @default(cuid())
  brandId   String
  brand     AdLibraryBrand @relation(fields: [brandId], references: [id], onDelete: Cascade)

  status         String   @default("queued")
  totalAds       Int      @default(0)
  classifiedAds  Int      @default(0)
  failedAds      Int      @default(0)
  skippedAds     Int      @default(0)

  anthropicBatchId String?
  batchSubmittedAt DateTime?
  batchCompletedAt DateTime?

  estimatedCostUsd Float?
  actualCostUsd    Float?
  inputTokens      Int?
  outputTokens     Int?

  errorMessage     String?

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@index([brandId, status])
  @@index([status, createdAt])
  @@index([anthropicBatchId])
}
```

**3. ApiCostLog** (add after ClassificationJob):

model ApiCostLog {
