<tasks>

<task type="auto">
  <name>Task 1: Diagnose current token status</name>
  <files></files>
  <action>
    Check the current status of Facebook access tokens by testing them against the Facebook Graph API.

    For each token (FACEBOOK_ACCESS_TOKEN1, FACEBOOK_ACCESS_TOKEN2, FACEBOOK_ACCESS_TOKEN3 from .env.local):

    1. Call the Facebook debug_token endpoint:
       ```
       curl -s "https://graph.facebook.com/debug_token?input_token=${TOKEN}&access_token=${TOKEN}" | jq '.data | {is_valid, expires_at, scopes}'
       ```

    2. Record for each token:
       - Is it valid?
       - When does it expire? (convert Unix timestamp to date)
       - What scopes does it have?

    3. Also test a real demographics call to confirm tokens work end-to-end:
       ```
       curl -s "https://graph.facebook.com/v21.0/ads_archive?search_terms=*&ad_reached_countries=['SE']&ad_type=POLITICAL_AND_ISSUE_ADS&fields=ad_delivery_start_time&limit=1&access_token=${TOKEN}" | jq '.error // "OK"'
       ```

    Report findings: which tokens are valid, which are expired, and what action is needed.
  </action>
  <verify>Token status documented for all 3 tokens</verify>
  <done>Clear diagnosis of which tokens are valid and which need refresh</done>
</task>

<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Refresh expired tokens</name>
  <action>
    Based on Task 1 diagnosis, refresh any expired tokens.
  </action>
  <instructions>
    For each expired token:

    1. Go to https://developers.facebook.com/tools/debug/accesstoken/
    2. Paste the expired token and click "Debug"
    3. Click "Extend Access Token" to get a new 60-day token
    4. If the token cannot be extended (fully expired), generate a new one:
       - Go to https://developers.facebook.com/tools/explorer/
       - Select your app
       - Click "Generate Access Token"
       - Then extend it using the debug tool above

    Update locally:
    - Edit `.env.local` with the new token values

    Update on Vercel:
    - Go to Vercel Dashboard > Project Settings > Environment Variables
    - Update FACEBOOK_ACCESS_TOKEN1, FACEBOOK_ACCESS_TOKEN2, FACEBOOK_ACCESS_TOKEN3
    - Redeploy (or trigger a new deployment)

    If ALL tokens are still valid (not expired), simply type "all valid" to continue.
  </instructions>
  <resume-signal>Type "done" after updating tokens, or "all valid" if no refresh needed</resume-signal>
</task>
