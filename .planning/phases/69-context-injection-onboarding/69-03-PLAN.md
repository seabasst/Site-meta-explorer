  <files>src/app/api/brand-profiles/interview/route.ts</files>
  <action>
Create a POST endpoint at `/api/brand-profiles/interview` that processes a conversational exchange and returns both a chat message and extracted profile fields.

**Request body:**
```
{
  messages: Array<{ role: 'user' | 'assistant', content: string }>,
}
```

**Implementation:**

1. Require auth via `auth()` from `@/auth`
2. Validate messages array exists and is non-empty
3. Use the Anthropic SDK (already in the project, same client as Hikaru) with a specialized system prompt:

INTERVIEW_SYSTEM_PROMPT:
```
You are a brand strategist helping a user define their brand profile through friendly conversation. Your goal is to naturally extract these fields:

- Brand name (required)
- Brand voice/tone description
- Market positioning (what makes them different)
- Target demographics (age, gender, location, income)
- Audience interests
- Customer pain points
- Mission statement

Guidelines:
- Ask one focused question at a time
- Be conversational, encouraging, and concise
- After each response, extract any profile fields you can identify
- After 3-5 exchanges, summarize what you've gathered and ask if anything needs correction
- If the user seems done, indicate high completeness

You MUST respond with valid JSON in this exact format (no markdown, no code fences):
{
  "message": "Your conversational response here",
  "extractedFields": {
    "name": null or "extracted value",
    "brandVoice": null or "extracted description",
    "positioning": null or "extracted positioning",
    "demographics": [] or ["extracted", "items"],
    "interests": [] or ["extracted", "items"],
    "painPoints": [] or ["extracted", "items"],
    "missionStatement": null or "extracted mission"
  },
  "completeness": 0.0 to 1.0
}
```

4. Call `client.messages.create()` with model `claude-sonnet-4-20250514`, max_tokens 1024, the system prompt, and the user's messages
5. Parse the response text content as JSON
6. If JSON parsing fails, return `{ message: responseText, extractedFields: {}, completeness: 0 }` as fallback
7. Return the parsed JSON as the response with status 200

**Response format:**
```
{
  message: string,
  extractedFields: {
    name: string | null,
    brandVoice: string | null,
    positioning: string | null,
    demographics: string[],
    interests: string[],
    painPoints: string[],
    missionStatement: string | null,
  },
  completeness: number
}
```

Use `export const dynamic = 'force-dynamic';` and `export const maxDuration = 30;`.

  </verify>

**Interview chat component (`src/app/dashboard/v2/onboarding/interview-chat.tsx`):**

Create a 'use client' component `InterviewChat` with props `{ darkMode: boolean, onComplete: (profileId: string) => void }`.

UI structure:
- Chat message list (scrollable container, auto-scroll to bottom on new messages)
- Messages rendered as bubbles: user messages right-aligned, AI messages left-aligned
- Text input at bottom with send button
- Progress indicator showing completeness percentage (from API response)
- When completeness >= 0.8 OR after 5+ exchanges, show a "Review Profile" button

State:
- `messages: Array<{ role: 'user' | 'assistant', content: string }>` — conversation history
- `extractedFields: object` — accumulated from each API response (merge new fields over old, keeping non-null values)
- `completeness: number` — from latest API response
- `loading: boolean` — during API call
- `showReview: boolean` — when user clicks "Review Profile"

Flow:
1. On mount, show a welcome message from the AI: "Hi! I'd love to help you set up your brand profile. Tell me about your brand — what's it called and what do you do?"
2. User types message, hits send
3. POST to `/api/brand-profiles/interview` with full message history
4. Display AI response, update extractedFields and completeness
5. When user clicks "Review Profile", show the extracted fields in an editable form (similar to wizard step layout — each field as an input/textarea that user can edit)
6. "Save Profile" button POSTs to `/api/brand-profiles` with the extracted (and possibly edited) fields
7. On success, call `onComplete(newProfileId)`

Styling: Match the Hikaru chat UI style (dark/light mode, similar bubble styling, similar input bar). Use Tailwind classes consistent with the project.

The mode selector should be clean and minimal — two cards with subtle borders, active state with primary color highlight.
