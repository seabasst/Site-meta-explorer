  <files>src/lib/brand-context.ts</files>
  <action>
Create `src/lib/brand-context.ts` with a single exported function `compileBrandContext(profile, options?)`.

Implementation details:
- Import `BrandProfileFull` from `./brand-profile-types`
- MAX_CHARS constant = 7500 (approximately 1875 tokens, leaves buffer under 2K)
- Options interface: `{ queryHint?: 'creative' | 'strategy' | 'analysis' | 'general'; maxChars?: number }`
- The function builds XML-tagged sections in priority order:
  1. `<brand_name>` — always included
  2. `<positioning>` — if present
  3. `<brand_voice>` — if present, truncate to 1500 chars
  4. `<target_demographics>` — join array with ", "
  5. `<audience_interests>` — join array with ", "
  6. `<customer_pain_points>` — join array with "; "
  7. `<mission>` — if present
  8. `<brand_colors>` — combine primary/secondary/accent if any exist
  9. `<competitors>` — competitor pageName values, max 5
- Internal `addSection(tag, content)` function that checks if adding the section would exceed maxChars budget. Returns false if it would exceed.
- If no sections were added, return empty string
- Otherwise wrap all sections in `<brand_context>...</brand_context>` with leading newlines
- Return format: `\n\n<brand_context>\n{sections}\n</brand_context>`

Follow the exact pattern from the research document (Pattern 1). This is a pure function with no side effects.
  </action>

  </verify>
