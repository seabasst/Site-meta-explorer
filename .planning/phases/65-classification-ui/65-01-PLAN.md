     ```
     });
     ```
     Then loop over classifications and CATEGORY_KEYS to build distribution counts (same pattern as diversity route lines 162-180).

  3. Add to the JSON response: `classificationCoverage: { classified: classifiedCount, total: totalAds }` and `classificationDistribution: distribution`.
