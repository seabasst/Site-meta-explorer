<task type="auto">
  <name>Task 1: Create AdDetailLightbox component</name>
  <files>src/app/dashboard/v2/ad-library/components/ad-detail-lightbox.tsx</files>
  <action>
Create a new component `AdDetailLightbox` with these props:
- `ad: Ad` — the full ad object
- `darkMode: boolean`
- `isSaved: boolean`
- `onToggleSave: (adId: string) => void`
- `onClose: () => void`

**Modal behavior:**
- Use `useEffect` for Escape key handler: `document.addEventListener('keydown', handler)` with cleanup
- Use `useEffect` to set `document.body.style.overflow = 'hidden'` on mount, restore to `''` on unmount
- Backdrop: `fixed inset-0 z-50 flex items-center justify-center bg-black/60 backdrop-blur-sm` with `onClick={onClose}`
- Content: `relative w-full max-w-4xl max-h-[90vh] mx-4 overflow-y-auto rounded-2xl` with `onClick={e => e.stopPropagation()}`
- X close button in top-right corner (use lucide `X` icon)

**Layout — Desktop two-column, mobile single-column:**

LEFT COLUMN (media, ~50% width on desktop, full width on mobile):
- Large media preview reusing same logic as AdCard's renderPreview but at larger dimensions
- If `primaryAsset` is video: `<video>` with controls, muted, playsInline, poster thumbnail, `max-h-[70vh] w-full object-contain`
- If `primaryAsset` is image: `<img>` with `max-h-[70vh] w-full object-contain`
- If no asset: text fallback showing body/title
- If multiple assets (carousel): show asset count badge, display first asset. Do NOT build carousel navigation — just indicate "N assets" so users know.

RIGHT COLUMN (details):

1. **Brand header:** Profile pic (or initial), brand name (as Link to brand page), category badge if present
2. **Ad copy section:** Full body text (no line-clamp), title if different from body, caption, linkDescription — each only shown if not null
3. **Stats grid** (2x2 or flexible):
   - Reach: `formatNumber(ad.reachEstimate)` or "N/A"
   - Spend: format as currency range using `ad.spendLower`, `ad.spendUpper`, `ad.currency`. Use `Intl.NumberFormat` with `style: 'currency'`. Show "N/A" if both null.
   - Impressions: format as range `formatNumber(lower) - formatNumber(upper)`. Show "N/A" if both null.
   - Duration: `ad.adDurationDays` days, or "N/A"
4. **Dates row:** Start date and end date formatted with `toLocaleDateString('en-US', { year: 'numeric', month: 'short', day: 'numeric' })`. Show "Ongoing" if endDate is null and isActive is true.
5. **Platforms:** Show `publisherPlatforms` as badges (capitalize, replace underscores with spaces)
6. **CTA section:** If `ctaText` exists, show it as a styled badge/button. If `linkUrl` exists, show it as a clickable link (truncated display, full href). Combine: "Shop Now -> example.com/..."
7. **Partnership:** If `bylines` exists, show partnership indicator with the bylines text
8. **Targeting:** If `targetingJson` is not null, try to render it. Since the shape is unknown, use a defensive approach: if it's an object, show key-value pairs; if it's a string, show as-is; otherwise show "Targeting data available" as fallback. Wrap in try-catch to prevent crashes.
9. **Action buttons** at bottom:
   - Save/Unsave button (Heart icon, filled if saved, calls `onToggleSave(ad.id)`)
   - View on Meta link (ExternalLink icon, opens `ad.snapshotUrl` in new tab, only if snapshotUrl exists)

**Dark mode:** Follow existing codebase pattern. Container: `darkMode ? 'bg-[#161b2e] border border-[#1235e2]/20 text-white' : 'bg-white border border-slate-200 text-slate-900'`. Use the same conditional class patterns as the login modal and ad-card.

**Graceful degradation:** EVERY optional field must have a null check. If null, either show "N/A" or hide that section entirely. Do not render empty sections.

**Imports needed:** `Ad` from `../types`, `formatNumber` from `../../v2-shell`, `Heart`, `X`, `ExternalLink`, `Calendar`, `Users`, `Globe`, `Clock`, `DollarSign`, `Eye`, `Link2` (or similar) from `lucide-react`, `Link` from `next/link`.

Use `'use client'` directive at top.
  </action>

  <action>
Wire the lightbox into the ad library page:

1. **Import:** Add `import { AdDetailLightbox } from './components/ad-detail-lightbox';` at top with other component imports.

2. **State:** Add `const [selectedAd, setSelectedAd] = useState<Ad | null>(null);` in the AdLibraryContent component, near the other UI state declarations.

3. **Pass onSelect to AdCard:** In the ads grid section where AdCards are rendered, add `onSelect={() => setSelectedAd(ad)}` prop:
   ```
   <AdCard key={ad.id} ad={ad} darkMode={darkMode} isSaved={savedAdIds.has(ad.id)} onToggleSave={toggleSaveAd} onSelect={() => setSelectedAd(ad)} compact={gridDensity === 'compact'} />
   ```

4. **Render lightbox:** Add the lightbox render AFTER the login modal section (before the closing `</V2Shell>` tag):
   ```
   {selectedAd && (
     <AdDetailLightbox
       ad={selectedAd}
       darkMode={darkMode}
       isSaved={savedAdIds.has(selectedAd.id)}
       onToggleSave={toggleSaveAd}
       onClose={() => setSelectedAd(null)}
     />
   )}
   ```

This is a minimal wiring change — 4 lines of meaningful code. The page does NOT need a new API call because all ad data is already loaded.
