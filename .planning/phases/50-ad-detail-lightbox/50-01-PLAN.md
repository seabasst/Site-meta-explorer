<task type="auto">
  <name>Task 2: Add onSelect prop to AdCard with click propagation handling</name>
  <files>src/app/dashboard/v2/ad-library/components/ad-card.tsx</files>
  <action>
Add an optional `onSelect` prop to AdCard:

1. Add `onSelect?: () => void` to the component props.

2. On the outer `<div>` wrapper: add `onClick={onSelect}` and conditionally add `cursor-pointer` class when onSelect is provided.

3. Prevent click propagation on interactive elements so they don't trigger onSelect:
   - **Video controls:** Wrap the preview area's content in a handler that checks if the click target is inside a `<video>` element. If so, call `e.stopPropagation()`. Apply this on the preview container div's onClick: `onClick={e => { if ((e.target as HTMLElement).closest('video')) e.stopPropagation(); }}`
   - **Save button:** Add `e.stopPropagation()` before calling `onToggleSave`. Change: `onClick={() => onToggleSave(ad.id)}` to `onClick={(e) => { e.stopPropagation(); onToggleSave(ad.id); }}`
   - **View on Meta link:** Add `onClick={e => e.stopPropagation()}` to the `<a>` tag.
   - **Brand name link:** Add `onClick={e => e.stopPropagation()}` to the `<Link>` component so clicking the brand name navigates to the brand page instead of opening the lightbox.

Do NOT change the visual appearance of the card. The only visual change is `cursor-pointer` when onSelect is provided.
  </action>
  <verify>Run `npx tsc --noEmit` — no type errors. Verify in browser: clicking card body triggers onSelect (can test with console.log temporarily), clicking video/save/meta-link/brand-name does NOT trigger onSelect.</verify>
