1. Create `src/app/dashboard/v2/brand-guidelines/page.tsx` as a 'use client' component:

**Data loading:**
- On mount, fetch GET `/api/brand-guidelines` to load existing guidelines
- If 401 (not authenticated), show a friendly message: "Sign in to set up your brand guidelines"
- If guidelines exist, populate form with saved values
- Use react-hook-form with zodResolver for form state management (both already installed)

**Form sections (use V2Card for each section, V2SectionTitle for headers):**

a) **Brand Voice & Mission** (V2Card):
   - "Brand Voice & Personality" textarea (max 2000 chars) with placeholder: "Describe your brand's tone of voice, personality traits, and communication style..."
   - "Mission Statement" textarea (max 1000 chars) with placeholder: "What is your brand's mission or purpose?"
   - Character count indicator for each textarea

b) **Target Audience** (V2Card):
   - "Demographics" section with toggle pills (TogglePill component, inline):
     - Gen Z 18-24, Millennials 25-40, Gen X 41-55, High Income, Urban Dwellers
   - "Interests" section with toggle pills:
     - Tech Early Adopters, Sustainable Living, Luxury Travel, Remote Work
   - Selected pills use `bg-[#1235e2] text-white`, unselected use muted background
   - Store selected IDs in string arrays

c) **Visual Identity** (V2Card):
   - Logo upload area: dropzone or click-to-upload. Show preview thumbnail when uploaded. "Max 4MB" note. Accept image/png, image/jpeg, image/webp, image/svg+xml.
   - On file select, POST to `/api/brand-guidelines/upload` with FormData (file + type='logo'). On success, update form state with returned url.
   - Three color swatches: Primary, Secondary, Accent. Each has a hidden `<input type="color">` behind a styled swatch (40x40 rounded square showing the color) plus a hex text input. Use the ColorSwatch pattern from RESEARCH.md.
   - Default colors: primary #1235e2, secondary #101322, accent #f6f6f8

d) **Reference Images** (V2Card):
   - Grid of image slots (2 cols on mobile, 4 cols on desktop)
   - "Add" button to upload reference images (same upload endpoint with type='reference')
   - Show uploaded images as thumbnails with a remove button (X overlay)
   - On remove: delete from referenceImages array in form state (actual R2 deletion happens on save)
   - Counter: "{N}/10 used"
   - Note: "Reference images serve as your visual mood board. They are not used directly in AI generation."

**Save behavior:**
- "Save Guidelines" button at bottom of page
- On submit, PUT to `/api/brand-guidelines` with all form fields
- Show loading state (spinner on button, disable while submitting) using react-hook-form's `isSubmitting`
- Show success toast/message on save (use a simple inline "Saved!" message that fades after 2s, or use sonner if available)
- Debounce is NOT needed -- explicit save button only

**Dark/light mode:**
- Use `useV2()` context for dark mode detection (same as all V2 pages)
- Apply dark mode classes: dark backgrounds `bg-slate-900/bg-slate-800`, light `bg-white/bg-slate-50`
- Follow the exact same styling patterns as `creative-lab/page.tsx`

**Design reference:**
- Figma file `w3UPPS0z6hGsWPoZWxXjkO` node `0:3` -- adapt to existing design system
- Use #1235e2 primary, V2Shell/V2Card/V2SectionTitle components
- Clean spacing, consistent with the rest of the V2 dashboard
