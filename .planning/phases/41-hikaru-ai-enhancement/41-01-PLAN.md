  <action>
Create a new file `src/app/dashboard/v2/hikaru/hikaru-charts.tsx` that exports:

1. **`ChartSpec` type** — the JSON schema the AI will output:
```typescript
export type ChartSpec = {
  type: 'bar' | 'pie' | 'area' | 'horizontal-bar';
  title: string;
  data: { name: string; value: number; [key: string]: unknown }[];
  keys?: string[];        // for multi-series bar/area
  colors?: string[];      // override default palette
  xKey?: string;          // default: 'name'
  valueFormatter?: 'number' | 'reach' | 'percent';
};
```

2. **`HikaruChart` component** — accepts `{ spec: ChartSpec; darkMode: boolean }` and renders the appropriate chart via a switch on `spec.type`.

3. **Four internal chart components:**
   - `HikaruBarChart` — vertical bar chart using Recharts `BarChart`. Supports multi-series via `spec.keys` array (defaults to `['value']`).
   - `HikaruPieChart` — donut-style pie chart using Recharts `PieChart` with `innerRadius={60} outerRadius={100}`.
   - `HikaruAreaChart` — area chart using Recharts `AreaChart`. X-axis from `spec.xKey || 'name'`. Supports multi-series via `spec.keys`.
   - `HikaruHorizontalBarChart` — horizontal bar chart using Recharts `BarChart` with `layout="vertical"`. Good for ranked lists.

**Styling rules (match dashboard charts):**
- Color palette: `['#1235e2', '#10b981', '#f59e0b', '#ef4444', '#8b5cf6']` — same as `format-distribution-chart.tsx`
- Chart container: fixed 250px height, full width. Use `<div className="rounded-xl border p-4 my-3 ...">` with dark mode conditional classes (NOT V2Card — self-contained for chat context).
- Dark mode: `darkMode ? 'bg-[#1235e2]/5 border-[#1235e2]/10' : 'bg-white border-slate-200'`
- CartesianGrid: `strokeDasharray="3 3"`, stroke `darkMode ? '#1e293b' : '#e2e8f0'`
- Axis ticks: `fontSize: 11, fill: darkMode ? '#94a3b8' : '#64748b'`
- Tooltip: `backgroundColor: darkMode ? '#1e293b' : '#fff'`, `border: 1px solid ${darkMode ? '#334155' : '#e2e8f0'}`, `borderRadius: 8`, `color: darkMode ? '#e2e8f0' : '#1e293b'`
- Bar radius: `[4, 4, 0, 0]` for vertical bars
- Title: `<h4 className="text-sm font-semibold mb-3">{spec.title}</h4>`
- Small disclaimer below chart: `<p className="text-[10px] mt-2 opacity-50">Data from AI analysis</p>`

**Value formatting:** Create a `formatValue` helper that formats numbers based on `spec.valueFormatter`:
- `'number'` or undefined: `toLocaleString()` (1,234)
- `'reach'`: format like dashboard (1.2M, 450K, etc.)
- `'percent'`: append `%`

Use this in Tooltip formatter.

**Important:** Do NOT import V2Card or useV2 — darkMode is passed as a prop to keep charts self-contained.
