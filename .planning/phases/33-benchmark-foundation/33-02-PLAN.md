State management:
- entries: BrandEntry[] (managed list of URLs with status)
- name: string (benchmark name, auto-populated from baseline pageName)
- isCreating: boolean (true during API call)
- progress: { total: number; completed: number; current: string | null }

Flow:
1. **Add phase**: User adds 2-6 URLs via BenchmarkBrandList
   - First added URL auto-set as baseline (user can change)
   - Validate: at least 2 entries, exactly 1 baseline

2. **Create button**: "Create Benchmark" button at bottom
   - Disabled if < 2 entries or no baseline or isCreating
   - On click: call POST /api/benchmarks

3. **Progress display** (when isCreating):
   - Show progress component: "Analyzing brands... X of Y complete"
   - Progress bar
   - Current brand name being fetched (if API provides streaming - otherwise just spinner)

4. **API call**:
   ```typescript
   const res = await fetch('/api/benchmarks', {
     method: 'POST',
     headers: { 'Content-Type': 'application/json' },
     body: JSON.stringify({
       name: name || `Benchmark: ${baselineEntry.url}`,
       urls: entries.map(e => e.url),
       baselineIndex: entries.findIndex(e => e.isBaseline),
     }),
   });
   ```

5. **Success handling**:
   - Show success toast (sonner): "Benchmark created!"
   - Redirect to /dashboard/benchmarks or /dashboard/benchmarks/[id]

6. **Error handling**:
   - Update entry statuses based on `failed` array in response
   - Show error toast with message
   - Allow user to remove failed entries and retry

7. **Name input** (optional):
   - Text input above create button: "Benchmark name (optional)"
   - Default: auto-generate from baseline brand name after creation

Styling: Glass card container, consistent with dashboard components.
