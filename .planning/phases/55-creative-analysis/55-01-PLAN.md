<task type="auto">
  <name>Task 2: Create /api/analyze/benchmark endpoint</name>
  <files>src/app/api/analyze/benchmark/route.ts</files>
  <action>
Create `src/app/api/analyze/benchmark/route.ts` as a POST endpoint accepting `{ pageId: string, category: string }`.

**Flow:**

1. Validate inputs: both `pageId` and `category` are required strings. Return 400 if missing.

2. Look up the brand: `prisma.adLibraryBrand.findUnique({ where: { pageId }, select: { id, pageName, category } })`. Return 404 if not found.

3. Check for cached analysis for the selected brand:
   ```typescript
   const brandCache = await prisma.brandAnalysisCache.findUnique({
     where: { brandId: brand.id }
   });
   ```
   If no cache exists, return a response with `{ needsAnalysis: true, brandName: brand.pageName, message: "Run Andromeda analysis for this brand first" }` and status 200 (not an error — the frontend will handle this by running analysis first).

4. Fetch all cached analyses for the category:
   ```typescript
   const categoryAnalyses = await prisma.brandAnalysisCache.findMany({
     where: {
       brand: { category: { equals: category, mode: 'insensitive' } }
     },
     include: { brand: { select: { pageName: true } } }
   });
   ```

5. Count total brands in category (for "X of Y analyzed" display):
   ```typescript
   const totalBrandsInCategory = await prisma.adLibraryBrand.count({
     where: { category: { equals: category, mode: 'insensitive' } }
   });
   ```

6. Compute category averages across all cached analyses (excluding the user's own brand to avoid self-comparison bias — filter out entries where brandId === brand.id):
   - Average each score field: formatScore, toneScore, journeyPhaseScore, visualStyleScore, messengerScore, overallScore, andromedaScore
   - Average key metrics: avgRefreshRate, stalePercentage, hookQualityAvg, uniqueConcepts, uniqueCtas
   - Average funnel: funnelAwareness, funnelConsideration, funnelConversion
   - Use `Math.round()` for integer averages, keep one decimal for floats
   - If no OTHER brands have cached analysis (only the user's brand), use all category analyses including the user's brand (better than empty)

7. Compute per-pillar indexing — for each pillar, calculate:
   ```typescript
   const diff = brandScore - categoryAvg;
   const status = diff > 5 ? 'strength' : diff < -5 ? 'gap' : 'neutral';
   ```
   Pillars: format, tone, journeyPhase, visualStyle, messenger, overall, andromeda

8. Generate a `recommendations` array (3-5 items) based on indexing:
   - For each pillar where status is 'gap', create a recommendation object:
     ```typescript
     { pillar: string, brandScore: number, categoryAvg: number, diff: number, status: 'gap', message: string }
     ```
   - Message format: "Your {pillar} diversity score ({brandScore}) is {Math.abs(diff)} points below the {category} average ({categoryAvg}). Consider diversifying your {pillar} mix."
   - Sort recommendations by diff ascending (biggest gaps first)
   - Also include strengths with message: "Your {pillar} score ({brandScore}) outperforms the {category} average ({categoryAvg}) by {diff} points."

9. Return response matching this shape:
   ```typescript
   {
     brand: {
       name: string,
       scores: { format, tone, journeyPhase, visualStyle, messenger, overall },
       andromedaScore: number,
       metrics: { avgRefreshRate, stalePercentage, hookQualityAvg, uniqueConcepts, uniqueCtas, funnelAwareness, funnelConsideration, funnelConversion }
     },
     category: {
       name: string,
       slug: string,
       totalBrands: number,
       analyzedBrands: number,
       avgScores: { format, tone, journeyPhase, visualStyle, messenger, overall },
       avgAndromedaScore: number,
       avgMetrics: { avgRefreshRate, stalePercentage, hookQualityAvg, uniqueConcepts, uniqueCtas, funnelAwareness, funnelConsideration, funnelConversion }
     },
     indexing: {
       format: { brand, category, diff, status },
       tone: { brand, category, diff, status },
       journeyPhase: { brand, category, diff, status },
       visualStyle: { brand, category, diff, status },
       messenger: { brand, category, diff, status },
       overall: { brand, category, diff, status },
       andromeda: { brand, category, diff, status }
     },
     gaps: Recommendation[],
     strengths: Recommendation[],
     analyzedAt: string // brandCache.analyzedAt ISO string
   }
   ```

10. Set `export const dynamic = 'force-dynamic';` at the top.

**Error handling:** Wrap everything in try/catch, return 500 with `{ error: message }` on failure.
