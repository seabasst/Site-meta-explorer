<task type="auto">
  <name>Task 2: Create AnalysisView component</name>
  <files>src/app/dashboard/v2/creative-lab/analysis-view.tsx</files>
  <action>
Create a new `analysis-view.tsx` component (~250-300 LOC) that:

**Props interface:**
```typescript
interface AnalysisViewProps {
  brand: { pageId: string; pageName: string; iconUrl?: string; source: string };
  darkMode: boolean;
  onGenerateCreatives: () => void;   // Callback to transition to config state
  onGenerateBrief: () => void;       // Callback to transition to brief-loading state
  onBack: () => void;                // Callback to go back to mode-select
}
```

**Behavior on mount:**
1. Check if analysis cache exists by calling `POST /api/analyze/diversity` with `{ pageId: brand.pageId }`. The API auto-caches -- if cache exists it returns immediately, if not it runs full analysis (30-60s).
2. Show a loading skeleton during analysis (similar pattern to config-screen loading). Include a text message: "Analyzing [brand name]'s creative strategy..." with a note "(This may take up to a minute for first-time analysis)".
3. On success, store the diversity result (scores, distribution, andromedaMetrics).
4. After diversity analysis succeeds, call `POST /api/analyze/benchmark` with `{ pageId: brand.pageId, category: brand.source }` (the brand's source field contains the category). If benchmark fails (e.g., not enough brands in category), show diversity scores only without benchmark -- do NOT treat this as a fatal error.
5. Render results in this order:
   - **Diversity scores summary** -- a row of 5 small score pills showing each pillar score (format, tone, journeyPhase, visualStyle, messenger) plus overall. Use colored badges like `bg-blue-500/10 text-blue-400` with score number.
   - **BenchmarkComparison** -- import and render with the benchmark result (if available). Pass no pillarConfig (use the new default).
   - **Action CTAs section** -- Below benchmark, render a section titled "Take Action" with two cards in a 2-column grid:
     - Card 1: "Generate Ad Creatives" with Sparkles icon -- "AI will create images targeting your diversity gaps." Button calls `onGenerateCreatives`.
     - Card 2: "Generate UGC Brief" with FileText icon -- "Get a structured creator brief based on this brand's data." Button calls `onGenerateBrief`.
6. Error state: If diversity analysis fails, show error with retry button (call the analysis again) and a back button.

**Styling:** Follow existing patterns from page.tsx -- use V2Card, same dark/light mode classes, #1235e2 primary color. Import Sparkles, FileText, BarChart3, Loader2, AlertTriangle, RefreshCw from lucide-react.

Export the component as a named export: `export function AnalysisView(...)`.
  </action>
