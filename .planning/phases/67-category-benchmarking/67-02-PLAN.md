```typescript
interface ValueIndex {
  value: string;
  label: string;
  brandPct: number;
  categoryPct: number;
  indexScore: number;
  status: 'over-indexed' | 'under-indexed' | 'in-line' | 'unique';
}

// Add to BenchmarkResult:
distributionComparison?: Record<string, ValueIndex[]>;
```

**2. Create DistributionCategory sub-component:**
An expandable/collapsible section for one taxonomy category. Pattern:
- Header row: category label (colored dot) + expand/collapse chevron
- When expanded, show a list of ValueIndex rows
- Each row: taxonomy value label, two horizontal bars (brand = blue `#1235e2`, category = gray/slate), percentage labels, index badge
- Bar layout (per the research):
  ```
  [Label]  [====== brand bar (blue) ======] 35%   [2.1x badge]
           [========= category bar (gray) =========] 20%
  ```
- Index badge colors:
  - over-indexed (>=1.5x): `bg-emerald-500/10 text-emerald-400` with badge text like "2.1x"
  - under-indexed (<=0.5x): `bg-red-500/10 text-red-400` with badge text like "0.5x"
  - in-line: `bg-slate-500/10 text-slate-400` (or omit badge for cleaner look)
  - unique: `bg-purple-500/10 text-purple-400` with "Unique" text
- Sort values within each category: over-indexed first (highest index), then in-line, then under-indexed (lowest index)
- Use `useState` to track expanded categories (default: first 3 expanded)
- Import ChevronDown and ChevronRight from lucide-react (add to existing imports)

**3. Add Distribution Comparison section to main component:**
After the existing "Gaps and Strengths" grid (the last section), add:
- A new V2Card section with header "Distribution Comparison" and BarChart3 icon
- Subtitle: "How your creative mix compares to {category} averages"
- Render a DistributionCategory for each of the 8 CATEGORY_KEYS
- Only render this section if `result.distributionComparison` exists and is non-empty
- Use the existing `config` (DEFAULT_CATEGORY_CONFIG) for labels and colors

**4. Style guidelines:**
- Follow existing dark mode patterns (use `darkMode` prop, same `muted` variable pattern)
- Bar max width: 100% of container, scale to max value between brand and category
- Keep bars thin (h-2 or h-2.5) — not chunky
- Compact spacing — this section can be long with 8 categories x ~5-10 values each
- Use the same V2Card component for consistency
- Respect existing design system: `#1235e2` primary blue, dark (#101322) / light (#f6f6f8)

Do NOT modify existing sub-components (PillarComparisonBar, ScoreCard) or existing sections. Only ADD new code below the existing gaps/strengths grid.
