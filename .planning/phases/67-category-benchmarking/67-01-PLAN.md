<task type="auto">
  <name>Task 1: Create benchmark utility functions</name>
  <files>src/lib/classification/benchmark-utils.ts</files>
  <action>
Create `src/lib/classification/benchmark-utils.ts` with two exported functions and a type:

1. **`ValueIndex` interface** (exported):
   ```
   value: string, label: string, brandPct: number (0-100), categoryPct: number (0-100),
   indexScore: number (e.g. 2.1), status: 'over-indexed' | 'under-indexed' | 'in-line' | 'unique'
   ```

2. **`computeCategoryAvgDistribution(analyses, categoryKeys)`**:
   - Takes array of `{ distributionJson: unknown }` objects (BrandAnalysisCache rows)
   - For each category key in CATEGORY_KEYS, iterate over ALL taxonomy values from `TAXONOMY[key].values`
   - For each value, collect counts from each brand's distributionJson (missing = 0)
   - Average the counts across brands
   - Return `Record<CategoryKey, Record<string, number>>` — category avg distribution
   - Import TAXONOMY, CATEGORY_KEYS, CategoryKey from `@/lib/classification/taxonomy`

3. **`computeValueIndices(brandDist, categoryAvgDist, categoryKey)`**:
   - Takes brand distribution (Record<string, number>), category avg distribution (Record<string, number>), and the category key
   - Reads `TAXONOMY[categoryKey].values` and `TAXONOMY[categoryKey].labels` directly
   - Converts both to percentages (count / total * 100)
   - Computes index score = brandPct / categoryPct
   - Handles edge cases:
     - categoryPct === 0 && brandPct > 0: status = 'unique', indexScore = Infinity
     - both 0: skip (filter out)
     - indexScore >= 1.5: 'over-indexed'
     - indexScore <= 0.5: 'under-indexed'
     - else: 'in-line'
   - Round pcts to 1 decimal, indexScore to 1 decimal
   - Filter out values where both brand and category are 0
   - Return ValueIndex[]

Follow the exact computation logic from 67-RESEARCH.md code examples. Use `as const` patterns consistent with taxonomy.ts.
  </action>
  <verify>
Run `npx tsc --noEmit` to confirm no type errors. Manually inspect that TAXONOMY import resolves correctly and both functions are exported.
  </verify>
  <done>benchmark-utils.ts exports computeCategoryAvgDistribution, computeValueIndices, and ValueIndex type. TypeScript compiles clean.</done>
</task>
