3. **Add monitor check effect** — after the brand data loads (when `brand` is set), call the check endpoint to determine initial monitor state. Use `brand.id` (internal cuid), NOT `pageId` (URL param):
   ```
   useEffect(() => {
     if (!brand) return;
     fetch('/api/ad-library/brands/monitor/check', {
       method: 'POST',
       headers: { 'Content-Type': 'application/json' },
       body: JSON.stringify({ brandIds: [brand.id] }),
     })
       .then(res => res.json())
       .then(data => {
         setIsMonitored((data.monitoredBrandIds || []).includes(brand.id));
       })
       .catch(() => {}); // Graceful fallback for unauthenticated
   }, [brand?.id]);
   ```
