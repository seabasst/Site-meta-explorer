  <files>src/app/dashboard/v2/creative-lab/ugc-brief-view.tsx</files>
  <action>
    Create a new component `UGCBriefView` that renders a full UGC brief and provides export actions. Props: `{ brief: UGCBrief; darkMode: boolean; onBack: () => void }`.

    **Layout structure** (follow existing V2Card/design system patterns -- `#1235e2` primary, dark `#101322` / light `#f6f6f8`):

    1. **Header bar** with brief title, brand name, and metadata badges (platform, duration, aspect ratio, content type). Include a back arrow button (calls onBack).

    2. **Action buttons row** (top-right or below header):
       - "Copy to Clipboard" button (ClipboardCopy icon from lucide-react) -- copies formatted plain text version of the brief using `navigator.clipboard.writeText()`.
       - "Download Markdown" button (Download icon from lucide-react) -- downloads as `.md` file using Blob + createObjectURL + anchor click pattern.
       - Show a brief toast/feedback when copy succeeds (simple state toggle, "Copied!" text for 2 seconds, no external toast library needed).

    3. **Hooks section** -- numbered list of 3 hook options, each in a styled card/row. Label: "Hook Options (test all 3)".

    4. **Shot List section** -- render each scene as a card with: scene number badge, duration, shot type tag, description, visual notes (camera icon), audio notes (mic icon). Use a vertical timeline or card grid layout.

    5. **Talking Points section** -- bulleted list of 3-5 talking points.

    6. **B-Roll Suggestions section** -- bulleted list with film icon.

    7. **CTA section** -- single styled block.

    8. **Tone & Style section** -- tone description + Do's (green checkmarks) and Don'ts (red x marks) side by side.

    9. **Brand Context section** (collapsible or subtle) -- key product info and target audience.

    **Utility functions** (inside the component file):
    - `formatBriefAsText(brief: UGCBrief): string` -- converts brief to clean plain text with headers, bullets, and spacing. Follow the exact format from the research document's code example.
    - `formatBriefAsMarkdown(brief: UGCBrief): string` -- converts to markdown with `#`, `##`, `-`, `|` table for shot list.
    - `downloadBriefAsMarkdown(brief: UGCBrief): void` -- creates Blob, triggers download via anchor element, revokes URL.

    **Styling:** Use the same Tailwind patterns as ConfigScreen and GenerationGallery -- rounded-xl cards, border colors based on darkMode, consistent spacing. Use lucide-react icons throughout.
