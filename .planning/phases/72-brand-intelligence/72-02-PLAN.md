**Enhance `/api/strategy/[pageId]/route.ts`:**

After fetching brand data (step 1), add a query for an associated BrandProfile:
```typescript
// Find BrandProfile where a competitor links to this brand's AdLibraryBrand
// This means: find profiles that track this brand
const brandProfile = await prisma.brandProfile.findFirst({
  where: {
    isActive: true,
  },
  include: {
    competitors: {
      include: {
        adLibraryBrand: { select: { id: true, pageId: true, pageName: true } },
      },
    },
  },
  orderBy: { updatedAt: 'desc' },
});
```

Add the profile data to the response (new optional field):
```typescript
return Response.json({
  brand: brandProfile,
  classificationCoverage,
  taxonomyBreakdown,
  diversityScores,
  gapMatrix,
  maxCellCount,
  // NEW: optional brand profile context for personalized recommendations
  brandContext: brandProfile ? {
    name: brandProfile.name,
    positioning: brandProfile.positioning,
    brandVoice: brandProfile.brandVoice,
    demographics: brandProfile.demographics,
    painPoints: brandProfile.painPoints,
    interests: brandProfile.interests,
  } : null,
});
```

**Create `/api/strategy/personalized/route.ts`:**

POST endpoint accepting `{ pageId, diversityScores, weakCategories, gapCount }`.

1. Look up AdLibraryBrand by pageId.
2. Find the active BrandProfile (same query as above).
3. If no profile, return `{ needsProfile: true }`.
4. Use `compileBrandContext(profile, { queryHint: 'strategy' })` to build brand context.
5. Build a prompt for Claude Haiku 4.5 (`claude-haiku-4-5-20250415`) that includes:
   - Brand context XML from compileBrandContext.
   - The diversity scores summary (which pillars are weak/strong).
   - Number of gap matrix empty cells.
   - Ask for 3-5 personalized, actionable strategy recommendations that specifically reference the brand's audience, positioning, and voice.
6. Call Anthropic API with max_tokens: 1000.
7. Parse the response and return as `{ insights: string[] }` — array of insight paragraphs.

Use existing patterns from `generate-concept/route.ts` for Anthropic API calls. Use Haiku for cost efficiency (this is a non-critical enhancement).

Handle errors: API failures return 500 with error message. Missing profile returns `{ needsProfile: true, message: "Create a brand profile for personalized insights" }`.
