  <name>Task 1: Brand Health API endpoint</name>
  <files>src/app/api/brand-health/route.ts</files>
  <action>
Create GET `/api/brand-health?pageId=XXX` endpoint that:

1. Accepts `pageId` query param (the user's brand they're currently viewing in Creative Lab).
2. Looks up the AdLibraryBrand by pageId, gets its BrandAnalysisCache (the user's scores).
3. Finds any BrandProfile that has this brand linked as a competitor OR that matches by name — but actually the simpler approach: find ALL BrandProfiles, check which ones have competitors linked. Instead, use this approach:
   - Find the BrandAnalysisCache for the user's pageId brand (their scores).
   - Find BrandProfiles (any, since no auth required) and their competitors via BrandCompetitor -> adLibraryBrand.
   - Since there's no direct link from BrandProfile to the user's own AdLibraryBrand, use the approach from RESEARCH: accept an optional `profileId` query param. If not provided, find any BrandProfile that has the pageId brand's competitors linked. If no profile found, return the user's scores only with empty competitors array.

Simpler approach (recommended by research — Option 3): The endpoint receives `pageId` (the brand the user is viewing). It fetches:
  a. The AdLibraryBrand + BrandAnalysisCache for that pageId (user's brand scores).
  b. All BrandProfiles (since no auth gate), find the first profile that has competitors. Use an optional `profileId` query param if multiple profiles exist.
  c. For that profile's competitors, batch-fetch BrandAnalysisCache using `findMany({ where: { brandId: { in: competitorBrandIds } } })`.
  d. Compute per-pillar indexing: for each of the 8 category scores + overall + andromeda, compute `{ user, competitorAvg, diff, status }` where status is 'ahead' (diff > 5), 'behind' (diff < -5), or 'even'.
  e. Derive `strengths` (pillars where ahead) and `gaps` (pillars where behind).

Return shape (follow BrandHealthResponse from RESEARCH):
```typescript
{
  userBrand: { name, pageId, iconUrl, scores: Record<CategoryKey | 'overall', number>, andromedaScore, metrics },
  competitors: Array<{ name, pageId, iconUrl, notes, scores, andromedaScore, hasAnalysis }>,
  comparison: {
    indexing: Record<CategoryKey | 'overall', { user, competitorAvg, diff, status }>,
    strengths: string[],
    gaps: string[],
  }
}
```

Handle edge cases:
- Brand not found: 404
- No BrandAnalysisCache for user's brand: return `{ needsAnalysis: true }`
- No competitors linked: return userBrand data + empty competitors array + null comparison
- Some competitors unanalyzed: include them with `hasAnalysis: false`, exclude from averages

Use existing patterns from `/api/analyze/benchmark/route.ts` for computeIndex logic and score extraction. Import CATEGORY_KEYS from taxonomy.

Run `npx tsc --noEmit` to verify no type errors.
Test with curl: `curl "http://localhost:3000/api/brand-health?pageId=SOME_PAGE_ID"` returns valid JSON with userBrand, competitors, and comparison fields.
  </verify>

API returns competitor comparison data with per-pillar indexing for any brand that has linked competitors via BrandProfile. Returns graceful responses for missing analysis, no competitors, or brand not found.
