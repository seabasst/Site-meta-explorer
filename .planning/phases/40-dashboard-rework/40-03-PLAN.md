**use-dashboard-config.ts:**

Follow the exact same localStorage pattern as `src/hooks/use-favorites.ts`. This is the proven pattern for this codebase.

```typescript
interface DashboardConfig {
  id: string;            // crypto.randomUUID()
  name: string;          // user-provided name
  filters: {
    displayFormat?: string;
    category?: string;
    startDate?: string;
    endDate?: string;
    isActive?: string;   // "true" | "false" | undefined
  };
  createdAt: string;     // ISO string
}
```

Storage key: `'dashboard-v2-configs'`
Max configs: 10

Hook exports:
- `configs: DashboardConfig[]` - all saved configs
- `isLoaded: boolean` - whether localStorage has been read
- `saveConfig(name: string, filters: Record<string, string>): boolean` - saves current filters as named config, returns false if at limit
- `loadConfig(id: string): DashboardConfig | undefined` - returns config by id
- `deleteConfig(id: string): void` - removes config
- `activeConfigId: string | null` - tracks which config is currently loaded (if any)
- `setActiveConfigId(id: string | null): void`

Same lifecycle as useFavorites:
- Load from localStorage in useEffect on mount
- Save to localStorage in useEffect when configs change (guard with isLoaded)
- Initialize state with empty array (avoid hydration mismatch)

**config-manager.tsx:**

Create a `ConfigManager` component. Props: none (uses hooks internally).

UI structure:
1. A row that sits in the filter bar area (or just below it) containing:
   - "Save View" button (opens a small inline form or popover with a text input for config name + Save button)
   - A dropdown/select showing saved configs by name, with "Load" behavior on selection
   - When a config is active, show its name as a pill/badge with an X to deactivate

2. Saved configs dropdown:
   - Each item shows: config name, created date (relative like "2 days ago")
   - Hover/click reveals a delete (trash) icon
   - Selecting a config calls `router.replace()` with the config's saved filters as URL params
   - Max 10 configs; when at limit, Save button is disabled with tooltip "Maximum 10 saved views"

3. Save flow:
   - Click "Save View" -> text input appears inline -> type name -> click Save or press Enter
   - Reads current URL searchParams to capture the filter state
   - Creates config via `saveConfig(name, currentFilters)`
   - Sets as active config

4. Load flow:
   - Select config from dropdown
   - `router.replace()` sets URL params to config.filters
   - Sets `activeConfigId` to loaded config

Styling: Match the filter bar styling from dashboard-filters.tsx. Use V2Card for the dropdown if needed. Dark mode via `useV2()`. Icons from lucide-react: `Save`, `Trash2`, `ChevronDown`, `X`.

IMPORTANT: Use `useSearchParams()` and `useRouter()` from next/navigation for reading/writing URL state. Same Suspense considerations as the filter bar.
