  <files>

  <action>
Extend the existing stats API to accept two new query parameters:

1. **`category`** (string, optional) - Filters all ad aggregations to ads from brands matching this category. Add to the `adWhereClause` as: `brand: { category: { equals: category, mode: 'insensitive' } }` (case-insensitive match since categories are normalized at API boundary per project decisions).

2. **`displayFormat`** (string, optional) - Filters all ad aggregations to ads matching this display format. Add to `adWhereClause` as: `displayFormat: displayFormat`. Can be comma-separated for multiple formats (e.g., `displayFormat=image,video`), in which case use `displayFormat: { in: displayFormat.split(',') }`.

3. **`isActive`** (string "true"/"false", optional) - Already partially supported in the ad count query. Extend to filter ALL aggregations (not just the activeAds count). Add to `adWhereClause` as: `isActive: isActive === 'true'` when the param is present.

Changes to the GET handler:
- Parse `category`, `displayFormat`, and `isActive` from searchParams
- Build `adWhereClause` incorporating these new filters alongside existing `brandFilter` and `dateFilter`
- For `category`: join through the brand relation: `{ brand: { category: { equals: category, mode: 'insensitive' } } }`
- For `displayFormat`: add directly to ad where clause
- For `isActive`: add `isActive: boolean` to ad where clause
- Update the cache key to include the new params
- All existing behavior unchanged when params are absent

IMPORTANT: The BigInt serialization helper (`serializeBigInt`) must remain. The in-memory cache pattern must remain. Do NOT change the response shape -- only filter the data.
  </action>

Filter controls (all render as styled select/button elements matching the dark mode pattern):

5. **Clear filters** button - Removes all filter params from URL.

Styling: Match existing filter bar pattern from the old dashboard (rounded-xl border, bg-[#1235e2]/5 dark, bg-slate-50 light). Use `V2Card` or the same manual classes. Each filter control: `px-3 py-2 rounded-lg text-sm font-medium border`.

URL sync pattern:
```
const updateFilter = (key: string, value: string | null) => {
  const params = new URLSearchParams(searchParams.toString());
  if (value) params.set(key, value);
  else params.delete(key);
  router.replace(`?${params.toString()}`);
};
```
