  - `SerializedBrand` interface: id, pageId, pageName, profilePicUrl, country, category, website, totalReach (string -- BigInt serialized), activeAdCount, ingestionStatus
  - `SerializedAd` interface: id, adId, displayFormat, body, caption, title, snapshotUrl, startDate, isActive, reachEstimate, assets array (id, assetType, storedUrl, thumbnailUrl, originalUrl, downloadStatus, position)
  - `BrandDetailResponse`: brand: SerializedBrand, ads: SerializedAd[], pagination: { page, limit, total, totalPages }

  **State:**
  - `brand` (SerializedBrand | null), `ads` (SerializedAd[]), `loading` (boolean), `error` (string | null)
  - `page` (number, default 1), `totalPages` (number), `total` (number)

  **Data fetching:**
  - `useParams()` to get `pageId`
  - `fetchBrandDetail` callback that calls `GET /api/ad-library/brands/${pageId}?page=${page}&limit=24`
  - Handle 404 (brand not found) with a friendly error state
  - Handle network errors gracefully
  - Re-fetch when `page` changes

  **Layout (inside V2Shell with title={brand?.pageName || 'Brand Detail'}):**

  1. **Back link** at top: arrow icon + "Back to Ad Library" linking to `/dashboard/v2/ad-library`

  2. **Brand header** (V2Card):
     - Profile pic (64x64 rounded-full) + brand name (text-2xl font-bold) + category badge
     - Stats row: Active Ads count, Total Reach (formatted), Country
     - Website link if available (external link icon)

  3. **Ad grid** (reuse the card rendering pattern from ad-library page):
     - Responsive grid: 1 col on mobile, 2 on md, 3 on lg
     - Each ad card shows: thumbnail/asset preview, ad body snippet (truncated to 3 lines), format badge (video/image/carousel), start date, reach estimate
     - For asset display: prefer `storedUrl` over `thumbnailUrl` over `snapshotUrl`. Show play icon overlay for videos.
     - Cards should NOT link anywhere (they're the detail level)

  4. **Pagination** at bottom: Previous/Next buttons with page X of Y display, disabled states at boundaries

  5. **Loading state**: V2Skeleton placeholders for header and 6 card slots

  6. **Error state**: V2Card with error message and back link

  **Styling:** Follow darkMode patterns from useV2() exactly as done in ad-library/page.tsx and categories/[slug]/page.tsx. Use the same Tailwind class patterns (dark:bg-[#1a1d2e], text-gray-400, etc.)
