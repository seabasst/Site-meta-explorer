<task type="auto">
  <name>Task 2: Create POST /api/classify/single route</name>
  <files>src/app/api/classify/single/route.ts</files>
  <action>
Create `src/app/api/classify/single/route.ts` with a `POST` handler.

The route:
1. Parses `{ adId }` from request body. Returns 400 if missing.
2. Cache check: `prisma.adClassification.findUnique({ where: { adId } })`. If exists, return `{ classification: existing, cached: true }` immediately (no Claude call).
3. Fetches the ad with brand and first image asset:
   ```
   prisma.adLibraryAd.findUnique({
     where: { id: adId },
     include: {
       brand: { select: { pageName: true, category: true } },
       assets: {
         where: { assetType: "image", downloadStatus: "completed" },
         take: 1,
         select: { storedUrl: true },
       },
     },
   })
   ```
   Returns 404 if ad not found.
4. Calls `classifySingleAd()` with ad data mapped to `AdInput`.
5. Persists classification:
   ```
   prisma.adClassification.create({
     data: {
       adId: ad.id,
       ...classification,
       classifiedBy: "haiku-4.5",
       classificationSource: ad.assets[0]?.storedUrl ? "vision" : "text",
       schemaVersion: 1,
     },
   })
   ```
6. Uses `after()` from `next/server` for fire-and-forget cost logging:
   ```
   after(() => {
     logApiCost({
       model: "claude-haiku-4-5-20251001",
       operation: "classify-single",
       inputTokens: usage.input_tokens,
       outputTokens: usage.output_tokens,
       brandId: ad.brandId,
     });
   });
   ```
7. Returns `{ classification: saved, cached: false }`.

Wrap the entire handler in try/catch. On error, return 500 with `{ error: "Classification failed", details: err.message }`.

Import `after` from `next/server` (Next.js 16 built-in). Import `prisma` from `@/lib/prisma`. Import `classifySingleAd` from `@/lib/classification/classify-single`. Import `logApiCost` from `@/lib/classification/cost-tracker`.
  </action>
