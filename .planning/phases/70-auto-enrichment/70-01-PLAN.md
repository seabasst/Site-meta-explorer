1. Add three fields to the BrandProfile model in prisma/schema.prisma:
   - `enrichmentHash String?` — SHA-256 prefix of input data
   - `enrichedAt DateTime?` — timestamp of last enrichment
   - `enrichmentSource String?` — "ad-library" | "website" | "interview"
   Run `npx prisma db push` to apply (shared Neon DB, no migration files needed).

2. Create `src/lib/enrichment/enrichment-hash.ts`:
   - Export `computeEnrichmentHash(data: { classificationSummary: Record<string, Record<string, number>>; adCount: number; topAdBodies: string[] }): string`
   - Use Node `crypto.createHash('sha256')` on JSON.stringify with sorted keys
   - Return first 16 chars of hex digest

3. Create `src/lib/enrichment/enrich-from-ads.ts`:
   - Export `enrichFromAds(brandId: string): Promise<EnrichmentResult>`
   - `EnrichmentResult` type: `{ fields: Partial<ProfileFields>; hash: string; adCount: number; model: string; inputTokens: number; outputTokens: number }`
   - Gather data using Promise.all:
     a. AdLibraryBrand (pageName, category, website)
     b. AdClassification (where ad.brandId, ad.isActive=true, take 100) — build distribution across 8 category keys (assetType, visualFormat, hookTactic, messagingAngle, awarenessStage, creativeMechanic, offerType, intendedAudience)
     c. AdAnalysis (where ad.brandId, ad.isActive=true, take 50) — select emotionalTone, visualStyle, targetAudience, messagingAngle
     d. AdLibraryAd (where brandId, isActive=true, take 20, orderBy startDate desc) — select body, ctaType, ctaText, title
   - Compute enrichment hash from classification distribution + adCount + unique bodies
   - Build prompt following the pattern in 70-RESEARCH.md "Enrichment LLM Prompt" section
   - Call Anthropic SDK with model "claude-haiku-4-5-20251001", max_tokens 1500
   - Parse JSON response, extract: brandVoice, positioning, demographics, interests, painPoints, missionStatement
   - Return EnrichmentResult with fields + hash + token usage
   - Minimum data guard: throw if adCount < 3 with descriptive error message
   - Use the system prompt from research: "You are a brand analyst. Given ad library data for a brand, extract brand profile information. Only extract what is clearly supported by the data. Return null for any field without strong evidence."
  </action>

<task type="auto">
  <name>Task 2: Enrichment API endpoint with change detection and cost budgets</name>
  <files>
    src/app/api/brand-profiles/[id]/enrich/route.ts
  </files>
  <action>
Create `src/app/api/brand-profiles/[id]/enrich/route.ts` with a POST handler:

1. Auth check: Use `auth()` from `@/auth`, get user, verify ownership of the profile (same pattern as existing `[id]/route.ts`).

2. Parse request body with zod:
   - `sourcePageId: z.string()` — required, the AdLibraryBrand.id to enrich from
   - `forceOverwrite: z.boolean().optional().default(false)` — whether to overwrite user-edited fields

3. Validate source brand exists and has enough data:
   - Query AdLibraryBrand by sourcePageId
   - If not found: return 404 "Source brand not found"
   - Count AdClassification where ad.brandId = sourcePageId and ad.isActive = true
   - If count < 3: return 400 "Not enough classified ads (need at least 3, found N)"

4. Cost budget check:
   - Call `getDailySpend()` from cost-tracker
   - If spend >= 2.0: return 429 "Daily enrichment budget exceeded ($2/day cap). Try again tomorrow."

5. Call `enrichFromAds(sourcePageId)` — this returns hash + fields + token usage.

6. Change detection:
   - Load existing profile's `enrichmentHash`
   - If hash matches and `forceOverwrite` is false: return 200 with `{ skipped: true, reason: "No new ad data since last enrichment" }`

7. Selective merge:
   - Build update object from enrichment fields
   - For each field (brandVoice, positioning, missionStatement): only include if current value is null/empty OR forceOverwrite=true
   - For array fields (demographics, interests, painPoints): if forceOverwrite=false, append-and-deduplicate (merge new values with existing, remove duplicates). If forceOverwrite=true, replace entirely.

8. Prisma update: Update BrandProfile with merged fields + set enrichmentHash, enrichedAt=new Date(), enrichmentSource="ad-library".

9. Log cost via `logApiCost({ model, operation: "enrich-from-ads", inputTokens, outputTokens, brandId: sourcePageId })`.

10. Return 200 with `{ profile: updatedProfile, enriched: true, fieldsUpdated: [list of field names that changed] }`.

Include the `profileInclude` pattern from the existing [id]/route.ts for returning competitors in the response.

Set `export const dynamic = 'force-dynamic'` and `export const maxDuration = 30`.
  </action>
  <verify>
    `npx tsc --noEmit` passes.
    `curl -X POST http://localhost:3000/api/brand-profiles/PROFILE_ID/enrich -H "Content-Type: application/json" -d '{"sourcePageId":"BRAND_ID"}' -H "Cookie: SESSION_COOKIE"` — returns enrichment result or appropriate error.
  </verify>
  <done>

  </done>
