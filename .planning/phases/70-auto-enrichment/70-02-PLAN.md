  <action>
Add an "Auto-Enrich from Ad Data" section to the brand profile form. This should appear prominently — either as a banner at the top of the form or as a dedicated section before the tabs.

1. In `brand-profile-form.tsx`, add an enrichment section:
   - Show only when the profile has at least 1 linked competitor (profile.competitors.length > 0). If no competitors linked, show a muted hint: "Link competitor brands to enable auto-enrichment from their ad data."
   - Source brand selector: dropdown populated from `profile.competitors` (show pageName + profilePicUrl). If only 1 competitor, pre-select it.
   - "Force overwrite" toggle (default off): small checkbox with label "Overwrite existing fields" and helper text "(By default, only empty fields are populated)"
   - "Auto-Enrich" button with Sparkles icon from lucide-react
   - Loading state: disable button, show Loader2 spinner, text changes to "Enriching..."
   - On success (enriched=true): toast.success showing which fields were updated (e.g., "Updated: brand voice, demographics, interests"). Trigger profile reload via the onUpdate callback.
   - On success (skipped=true): toast.info "No new ad data since last enrichment"
   - On error 429: toast.error with the budget message
   - On error 400: toast.error with the insufficient data message
   - On other errors: toast.error "Enrichment failed"

2. Style considerations (dark/light mode — use existing darkMode from useV2 context or props):
   - Use the project's `#1235e2` primary blue for the enrich button
   - Section should have a subtle border/background to distinguish it from manual form fields
   - Match existing form styling (rounded-lg borders, same input/label patterns)

3. In `page.tsx`, ensure the profile list refreshes after enrichment:
   - The BrandProfileForm already has an `onUpdate` callback pattern — use it to trigger `loadProfiles()` after enrichment succeeds
   - Also update `selectedProfile` state with the returned profile data so the form immediately reflects new field values without a full page reload

4. Show enrichment metadata when available:
   - If `profile.enrichedAt` exists, show a small muted line below the enrich button: "Last enriched: {relative time}" (use simple relative time like "2 hours ago", "yesterday")
   - Note: The BrandProfileFull type may need enrichedAt/enrichmentSource added to the select query. Check if the existing brand-profiles GET route returns these fields. If not, add them to the select/include in the GET route at `src/app/api/brand-profiles/route.ts` (the list endpoint) and `src/app/api/brand-profiles/[id]/route.ts`.

IMPORTANT: Do NOT add enrichedAt/enrichmentSource to the BrandProfileFull TypeScript type or Prisma queries unless the schema migration from Plan 01 has already been applied. The type should flow from Prisma's generated types.
