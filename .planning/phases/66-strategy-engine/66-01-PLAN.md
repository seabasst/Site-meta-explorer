<task type="auto">
  <name>Task 1: GET /api/strategy/[pageId] — Brand strategy data endpoint</name>
  <files>src/app/api/strategy/[pageId]/route.ts</files>
  <action>
Create a GET endpoint that assembles full strategy data for a brand from existing DB tables. No AI calls needed — this is pure data assembly.

**Request:** GET with pageId from URL params.

**Implementation steps:**

1. Look up AdLibraryBrand by pageId. Return 404 if not found.

2. Run these queries in parallel with Promise.all:
   - `prisma.brandAnalysisCache.findUnique({ where: { brandId: brand.id } })` — for diversity scores and distributionJson
   - `prisma.adClassification.findMany({ where: { ad: { brandId: brand.id, isActive: true } }, select: { awarenessStage: true, visualFormat: true } })` — for gap matrix computation
   - `prisma.adLibraryAd.count({ where: { brandId: brand.id, isActive: true } })` — total active ads for coverage denominator

3. If classifications count < 3, return 422 with `{ error: "...", needsClassification: true, classifiedCount, totalAds }` (same pattern as diversity route).

4. **Build taxonomyBreakdown:** If `cache.distributionJson` exists, use it directly (it's already the 8-category distribution). If not, fall back to computing from classifications (same loop pattern as diversity route lines 162-180).

5. **Build diversityScores:** Read the 8 score columns from BrandAnalysisCache (`assetTypeScore`, `visualFormatScore`, etc.) plus `overallScore`.

6. **Compute gapMatrix:** Initialize a nested Record with all awarenessStage values as outer keys and all visualFormat values as inner keys (all starting at 0). Loop through classifications to count co-occurrences. Also compute `maxCellCount` (highest value in any cell) for frontend color scaling.

7. **Build brand profile:** `{ pageName, category, website, activeAdCount, demographics: brand.demographicsJson }` from AdLibraryBrand.

8. **Build classificationCoverage:** `{ classified: classifications.length, total: totalActiveAds }`.

**Response shape (matches research spec):**
```typescript
{
  brand: { pageName, category, website, activeAdCount, demographics },
  classificationCoverage: { classified, total },
  taxonomyBreakdown: { assetType: {...}, visualFormat: {...}, ... }, // 8 categories
  diversityScores: { assetType: N, visualFormat: N, ..., overall: N },
  gapMatrix: { "unaware": { "talking-head": 0, ... }, ... }, // 5 stages x 12 formats
  maxCellCount: N,
}
```

**Important details:**
- Use `export const dynamic = 'force-dynamic';` (data changes as classifications are added)
- Import TAXONOMY and CATEGORY_KEYS from `@/lib/classification/taxonomy`
- Use the same brand lookup pattern as diversity route (find by pageId, return 404 if missing)
- The distributionJson in BrandAnalysisCache is typed as `Json` in Prisma — cast it as `Record<string, Record<string, number>>` when reading

  <name>Task 2: POST /api/strategy/generate-concept — Gap cell concept generation</name>
  <files>src/app/api/strategy/generate-concept/route.ts</files>
  <action>
Create a POST endpoint that generates a creative concept for a specific gap cell (awarenessStage + visualFormat combination) using Claude Haiku.

**Request body (validate with Zod):**
```typescript
const RequestSchema = z.object({
  pageId: z.string().min(1),
  awarenessStage: z.enum(TAXONOMY.awarenessStage.values),
  visualFormat: z.enum(TAXONOMY.visualFormat.values),
});
```

**Response schema (enforce with Zod):**
```typescript
const ConceptSchema = z.object({
  visualFormat: z.string(),
  creativeMechanic: z.string(),
  hook: z.string(),
  messagingAngle: z.string(),
  productionBrief: z.string(),
});
```

**Implementation steps:**

1. Parse and validate request body with RequestSchema. Return 400 on validation failure.

2. Look up brand by pageId (AdLibraryBrand). Return 404 if not found.

3. Fetch brand context in parallel:
   - BrandAnalysisCache (for distributionJson — what they already do)
   - Top 5 ads by reach with body text (for real copy context)

4. If no cache, return 404 with "Run analysis first" message.

5. Build Claude prompt. The prompt should include:
   - Brand name, category
   - Full taxonomy distribution from distributionJson (what they already do across all 8 categories)
   - The specific gap coordinates: awarenessStage label + visualFormat label (using TAXONOMY.awarenessStage.labels and TAXONOMY.visualFormat.labels)
   - Top ad copy excerpts (first 200 chars of body, max 5 ads)
   - Instruction: "Generate ONE creative concept that fills the gap at [awarenessStage] awareness stage using [visualFormat] format for [brandName]. The concept should complement their existing creative mix, not duplicate what they already have."
   - Output format instruction matching ConceptSchema fields
   - Each field description:
     - visualFormat: The specific visual execution (should match the requested format)
     - creativeMechanic: The storytelling technique (from taxonomy: before-after, listicle, reaction, etc.)
     - hook: The opening line/first 3 seconds that stops the scroll (1-2 sentences)
     - messagingAngle: The persuasion strategy (from taxonomy: price-value, problem-solution, etc.)
     - productionBrief: 3-5 sentence production brief covering concept, visual direction, copy angle, target audience, key moments

6. Call Claude Haiku (`claude-haiku-4-20250514`) with:
   - `max_tokens: 1000`
   - Parse response text, strip markdown fences, JSON.parse, validate with ConceptSchema

7. If parse fails, retry once with stronger JSON instruction (same pattern as `callClaudeWithRetry` in generate-strategy/route.ts, but inline — don't import from old route).

8. Return `{ concept: validatedConcept }`.

**Important details:**
- Use `export const dynamic = 'force-dynamic';`
- Use `export const maxDuration = 30;` (Haiku is fast, 30s is plenty)
- Import Anthropic SDK, prisma, TAXONOMY from classification/taxonomy, z from zod
- Do NOT reference or import anything from the old generate-strategy route — this is a clean implementation
- Do NOT persist concepts to database — they are ephemeral (shown in modal, user can copy)
