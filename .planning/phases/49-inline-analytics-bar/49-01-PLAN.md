    3. For top categories (category lives on AdLibraryBrand, not AdLibraryAd), use `prisma.$queryRaw`:
       ```typescript
       const topCategories = await prisma.$queryRaw<{ category: string; count: number }[]>`
         SELECT b.category, COUNT(a.id)::int as count
         FROM "AdLibraryAd" a
         JOIN "AdLibraryBrand" b ON a."brandId" = b.id
         WHERE b.category IS NOT NULL
         AND a.id IN (SELECT id FROM "AdLibraryAd" WHERE ... )
         GROUP BY b.category
         ORDER BY count DESC
         LIMIT 5
       `;
       ```
       IMPORTANT: Rather than reconstructing the full WHERE clause in raw SQL, use a simpler approach -- run the raw query with the same filter conditions that matter for categories. The cleanest approach: run a separate Prisma query to get distinct brandIds from the filtered set, then query categories from those brands. Example:
       ```typescript
       const brandIdsResult = await prisma.adLibraryAd.findMany({
         where,
         select: { brandId: true },
         distinct: ['brandId'],
       });
       const brandIds = brandIdsResult.map(r => r.brandId);
       const topCategories = brandIds.length > 0
         ? await prisma.adLibraryBrand.groupBy({
             by: ['category'],
             where: { id: { in: brandIds }, category: { not: null } },
             _count: { id: true },
             orderBy: { _count: { id: 'desc' } },
             take: 5,
           })
         : [];
       ```
       This avoids raw SQL entirely and uses Prisma's groupBy on the Brand model directly.
