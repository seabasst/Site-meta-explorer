  <files>src/components/dashboard/demographic-trend-chart.tsx</files>
  <action>
Create a tabbed trend chart component that visualizes demographic changes over time.

Props:
```typescript
interface DemographicTrendChartProps {
  trackedBrandId: string;
}
```

Component structure:
1. **State management:**
   - `activeTab`: 'age' | 'gender' | 'country' (default: 'age')
   - `loading`: boolean
   - `trendData`: { ageTrend, genderTrend, countryTrend, snapshotCount } | null

2. **Data fetching:**
   - useEffect to fetch from `/api/dashboard/trends?trackedBrandId=${trackedBrandId}`
   - Handle loading and error states

3. **Empty state (snapshotCount < 3):**
   ```jsx
   <div className="glass rounded-2xl p-6 text-center">
     <p className="text-[var(--text-muted)] text-sm mb-2">
       Need at least 3 snapshots to show trends
     </p>
     <p className="text-xs text-[var(--text-muted)]">
       Re-analyze this brand over time to track demographic changes
     </p>
   </div>
   ```

4. **Tab selector** (reuse pattern from TrendChart):
   ```jsx
   <div className="flex rounded-lg bg-[var(--bg-tertiary)] p-1 border border-[var(--border-subtle)]">
     {(['age', 'gender', 'country'] as const).map(tab => (
       <button
         key={tab}
         onClick={() => setActiveTab(tab)}
         className={`px-3 py-1 text-xs font-medium rounded-md transition-colors ${
           activeTab === tab
             ? 'bg-[var(--accent-green)] text-white'
             : 'text-[var(--text-secondary)] hover:text-[var(--text-primary)]'
         }`}
       >
         {tab === 'age' ? 'Age' : tab === 'gender' ? 'Gender' : 'Country'}
       </button>
     ))}
   </div>
   ```

5. **Chart area (300px height):**
   - Age chart: Multi-line with colors per age bracket
   - Gender chart: Multi-line (male=blue, female=pink, unknown=gray)
   - Country chart: Multi-line with top countries

**Recharts configuration (critical - from research):**
```jsx
<XAxis
  dataKey="timestamp"
  type="number"
  scale="time"
  domain={['dataMin', 'dataMax']}
  tickFormatter={(ts: number) =>
    new Intl.DateTimeFormat('en-GB', { day: '2-digit', month: 'short' }).format(new Date(ts))
  }
  tick={{ fill: 'var(--text-muted)', fontSize: 11 }}
  tickLine={false}
  axisLine={false}
/>
<YAxis
  domain={[0, 100]}
  tickFormatter={(v: number) => `${v}%`}
  tick={{ fill: 'var(--text-muted)', fontSize: 11 }}
  tickLine={false}
  axisLine={false}
  width={35}
/>
```

**Color palettes:**
- Age: Use AGE_COLORS from research (slate for 13-17, lime for 18-24, green for 25-34, etc.)
- Gender: blue-500 for male, pink-500 for female, gray-500 for unknown
- Country: Reuse COUNTRY_COLORS from TrendAnalysis (green, amber, red, purple, cyan)

**Tooltip:** Reuse ChartTooltip pattern from existing components.

Use 'use client' directive. Import from recharts: LineChart, Line, XAxis, YAxis, CartesianGrid, Tooltip, Legend, ResponsiveContainer.
