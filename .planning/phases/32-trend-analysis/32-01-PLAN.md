<task type="auto">
  <name>Task 1: Create demographics normalizer utility</name>
  <files>src/lib/demographics-normalizer.ts</files>
  <action>
Create a utility that normalizes `demographicsJson` from BrandSnapshot into a consistent shape.

The normalizer must handle both formats found in the database:
1. **Old format** (object-based): `{ gender: { male: 45, female: 55 }, age: { "18-24": 20, ... }, country: { DE: 30, ... } }`
2. **New format** (array-based): `{ genderBreakdown: [{gender, percentage}], ageBreakdown: [{age, percentage}], regionBreakdown: [{region, percentage}] }`

Implement:
```typescript
export interface NormalizedDemographics {
  ageBreakdown: { age: string; percentage: number }[];
  genderBreakdown: { gender: string; percentage: number }[];
  regionBreakdown: { region: string; percentage: number }[];
}

export function normalizeDemographicsJson(raw: unknown): NormalizedDemographics | null
```

Logic:
- Return `null` if raw is falsy or not an object
- Check for array fields first (new format) - use directly if present
- Fall back to object fields (old format) - convert `{ key: value }` to `[{ key, percentage: value }]`
- Handle `regionBreakdown` OR `country` OR `region` field names
- Sort ageBreakdown by age bracket (extract leading number)
- Sort regionBreakdown by percentage descending

Use the patterns from `demographic-aggregator.ts` for sorting age brackets.

<task type="auto">
  <name>Task 2: Create trends API endpoint</name>
  <files>src/app/api/dashboard/trends/route.ts</files>
  <action>
Create `GET /api/dashboard/trends` endpoint that returns demographic trend data for a tracked brand.

Query params:
- `trackedBrandId` (required) - The brand to get trends for
- `limit` (optional, default 30) - Max snapshots to return

Response shape:
```typescript
{
  ageTrend: DemographicTrendPoint[];
  genderTrend: GenderTrendPoint[];
  countryTrend: CountryTrendPoint[];
  snapshotCount: number;
}

interface DemographicTrendPoint {
  timestamp: number;     // Unix epoch ms (for Recharts time scale)
  date: string;          // Formatted date for display
  snapshotId: string;
  '13-17': number;
  '18-24': number;
  '25-34': number;
  '35-44': number;
  '45-54': number;
  '55-64': number;
  '65+': number;
}

interface GenderTrendPoint {
  timestamp: number;
  date: string;
  snapshotId: string;
  male: number;
  female: number;
  unknown: number;
}

interface CountryTrendPoint {
  timestamp: number;
  date: string;
  snapshotId: string;
  [countryCode: string]: number | string;  // Dynamic country keys
}
```

Implementation:
1. Auth check (same pattern as `/api/dashboard/snapshots`)
2. Verify brand ownership (ownerId OR trackerId = session.user.id)
3. Fetch snapshots ordered by `snapshotDate ASC` (oldest first for charts)
4. Select only: id, snapshotDate, demographicsJson
5. For each snapshot, normalize with `normalizeDemographicsJson()`
6. Build ageTrend: map age brackets to flat keys
7. Build genderTrend: map gender values to flat keys (default 0 if missing)
8. Build countryTrend: collect UNION of all top-5 countries across all snapshots, set 0 for missing
9. Format dates using `Intl.DateTimeFormat('en-GB', { day: '2-digit', month: 'short' })`

For countryTrend, use union approach from research:
- First pass: collect all countries that appear in top-5 of ANY snapshot
- Second pass: build data points with 0% for countries not in that snapshot
