  <files>prisma/schema.prisma, src/lib/brand-profile-types.ts</files>
  <action>
Add two new models to prisma/schema.prisma:

**BrandProfile model** (replaces/evolves BrandGuidelines):
- `id` String @id @default(cuid())
- `userId` String (FK to User, NOT unique — user can have multiple profiles)
- `name` String — brand name (required, max 100 chars in validation)
- `brandVoice` String? — tone of voice description
- `missionStatement` String? — mission/purpose
- `positioning` String? — market positioning statement
- `painPoints` String[] — customer pain points
- `demographics` String[] — target demographics
- `interests` String[] — audience interests
- `logoUrl` String? — public URL
- `logoKey` String? — R2 object key
- `primaryColor` String? — hex
- `secondaryColor` String? — hex
- `accentColor` String? — hex
- `referenceImages` Json? — array of {url, key, name}
- `isActive` Boolean @default(false) — whether this is the currently selected profile
- `createdAt` DateTime @default(now())
- `updatedAt` DateTime @updatedAt
- Relations: `user User`, `competitors BrandCompetitor[]`
- Indexes: `@@index([userId])`, `@@index([userId, isActive])`

**BrandCompetitor model** (links profile to existing AdLibraryBrand):
- `id` String @id @default(cuid())
- `profileId` String (FK to BrandProfile)
- `adLibraryBrandId` String (FK to AdLibraryBrand)
- `notes` String? — optional note about why this competitor matters
- `createdAt` DateTime @default(now())
- Relations: `profile BrandProfile`, `adLibraryBrand AdLibraryBrand`
- Constraints: `@@unique([profileId, adLibraryBrandId])`, `@@index([profileId])`

**Update User model:**
- Add `brandProfiles BrandProfile[]` relation

**Update AdLibraryBrand model:**
- Add `competitorOf BrandCompetitor[]` relation

**Keep BrandGuidelines model as-is** — we will migrate data in the API layer (Plan 02 will handle the soft migration on first settings page load). Do NOT drop BrandGuidelines yet.

**Create src/lib/brand-profile-types.ts:**
- `BrandProfileFull` — full profile with competitors (each competitor includes adLibraryBrand with pageId, pageName, profilePicUrl)
- `BrandProfileCreate` — fields for creating (name required, everything else optional)
- `BrandProfileUpdate` — partial update fields
- `BrandCompetitorWithBrand` — competitor entry with nested AdLibraryBrand info

After schema changes, run `npx prisma db push` to apply (this project uses db push, not migrations).
Run `npx prisma generate` to regenerate the client.

  <action>
**GET /api/brand-profiles** — List all profiles for authenticated user.
- Auth required (use `auth()` from `@/auth`, get user by email)
- Returns `{ profiles: BrandProfileFull[] }` including competitors with their AdLibraryBrand data
- Sort by updatedAt desc

**POST /api/brand-profiles** — Create a new profile.
- Auth required
- Validate with zod: name required (3-100 chars), all other fields optional
- If this is the user's first profile, set `isActive: true` automatically
- Returns `{ profile: BrandProfileFull }`

**GET /api/brand-profiles/[id]** — Get single profile.
- Auth required, verify ownership (profile.userId === user.id)
- Include competitors with AdLibraryBrand data
- Returns `{ profile: BrandProfileFull }`

**PUT /api/brand-profiles/[id]** — Update profile.
- Auth required, verify ownership
- Validate with zod (all fields optional except id from URL)
- If `isActive` is set to true, set all other user profiles to `isActive: false` (only one active at a time)
- Handle Json fields (referenceImages) with Prisma.JsonNull like the existing brand-guidelines route does
- Returns `{ profile: BrandProfileFull }`

**DELETE /api/brand-profiles/[id]** — Delete profile.
- Auth required, verify ownership
- Cascade deletes competitors (handled by Prisma onDelete: Cascade)
- If deleted profile was active, set the most recent remaining profile as active (if any)
- Returns `{ success: true }`

**POST /api/brand-profiles/[id]/competitors** — Link competitor brand.
- Auth required, verify profile ownership
- Body: `{ adLibraryBrandId: string, notes?: string }`
- Validate adLibraryBrandId exists in AdLibraryBrand table
- Max 10 competitors per profile (count check)
- Returns `{ competitor: BrandCompetitorWithBrand }`

**DELETE /api/brand-profiles/[id]/competitors** — Unlink competitor.
- Auth required, verify profile ownership
- Body: `{ competitorId: string }` (the BrandCompetitor record ID)
- Returns `{ success: true }`

All routes: `export const dynamic = 'force-dynamic'`, use try/catch with proper error responses (400, 401, 404, 500).

Follow the same patterns as `src/app/api/brand-guidelines/route.ts` for auth, error handling, and Prisma usage.
