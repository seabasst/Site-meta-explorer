**page.tsx — Brand Profiles settings page:**
- Layout: Left sidebar shows list of user's brand profiles (fetched from GET /api/brand-profiles), right side shows the selected profile's edit form
- "New Profile" button at top of sidebar list — opens form in create mode
- Each profile in sidebar list shows name + active badge (if isActive)
- Delete button on each profile (with confirmation) — calls DELETE /api/brand-profiles/[id]
- "Set as Active" button for non-active profiles — calls PUT /api/brand-profiles/[id] with { isActive: true }
- Use V2Shell with title="Brand Profiles", use V2Card for containers
- Use `toast` from `sonner` for success/error feedback
- Use `useV2()` for darkMode. Follow the design system: #1235e2 primary, dark (#101322) / light (#f6f6f8)

**brand-profile-form.tsx — Tab-based edit/create form:**
- 4 tabs: "Basics", "Voice & Positioning", "Audience", "Competitors"
- **Basics tab:** name (text input, required), missionStatement (textarea), pain points (tag input — type and press Enter to add chips, X to remove)
- **Voice & Positioning tab:** brandVoice (textarea with character count, max 2000), positioning (textarea)
- **Audience tab:** demographics (chip selector from common options + custom input), interests (same pattern)
- **Competitors tab:** renders the competitor-search.tsx component
- Visual identity section (collapsed/expandable): colors (3 hex inputs with color preview), logo upload placeholder (just show existing logoUrl if set, no upload in this plan)
- Form auto-saves on blur/change with 500ms debounce — calls PUT /api/brand-profiles/[id]
- For create mode: initially only show name field, after POST creates the profile, switch to full edit mode
- Use Tailwind for all styling. Tab bar should use the project's design language (underline active tab in #1235e2)

**competitor-search.tsx — Search and link competitors:**
- Search input that queries existing brands: `GET /api/ad-library/brands?search=` (the existing brand search endpoint)
- Dropdown results show brand name + pageId + category
- Click result to link: POST /api/brand-profiles/[id]/competitors with { adLibraryBrandId }
- Show linked competitors as cards with name, category, and X button to unlink
- Max 10 competitors shown, disable add button if at limit
- Toast feedback on link/unlink

Actually, add it to the sidebar: in the last section before settings, add `{ id: '/dashboard/v2/settings/brand-profiles', icon: Palette, label: 'Brand Profiles' }` in the standalone items section alongside Hikaru and Requests.

**brand-selector.tsx — Reusable brand selector dropdown:**
- Fetches user's brand profiles from GET /api/brand-profiles on mount
- Shows a dropdown button with the active brand name (or "No brand selected" if none)
- Dropdown list shows all profiles, click to select
- On selection: calls PUT /api/brand-profiles/[id] with { isActive: true } to persist, AND updates the URL search param `?brand={profileId}` using `useRouter().replace()` (shallow, no scroll)
- On mount, if `?brand=` param exists and differs from current active profile, set that profile as active
- Compact design: button is 32-36px height, fits in a header bar
- Props: `darkMode: boolean` for styling
- Use Lucide `ChevronDown` icon, subtle border styling matching the project design system
- If user has no profiles, show a small "Create profile" link to /dashboard/v2/settings/brand-profiles
- If user is not authenticated, don't render anything (graceful fallback)
